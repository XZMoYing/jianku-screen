## 2. 产品是什么、边界在哪

### 2.1 产品目标

一款同时提供**本地录屏、完整编辑、实时演示**的 macOS 工具：

- 录制保存独立画面、光标、按键、麦克风与系统声音轨道，结束后进入编辑器。
- 编辑器提供时间线、多轨叠加、自动/手动缩放、3D 运镜、光标平滑、动态模糊、背景/外框/阴影、字幕、书签、导出。
- 实时演示把同一套合成结果输出到副屏或会议软件可选的共享窗口，主屏不变。

硬性视觉目标：各种动画以参考产品（Screen Studio 3.7.5）的可观察行为为基准做逐帧对照；**未通过对照前不得宣称“百分之百一致”**，对外文案也不得使用竞品背书式表述。

### 2.2 首版范围与明确未完成

首版以 macOS 已实现的录制／编辑／导出／截图／实时演示为主体。以下**尚未达到发布门槛**，不要写成已完成：

- Windows／Linux 的实际构建、运行与适配（只有源码入口和矩阵盘点，见 `docs/跨平台能力与依赖矩阵.md`）。
- 完整中文与本土化逐页审计（U06/U07/U08）。
- 内部安全／隐私／依赖审计（U09/U10/U11）。
- 严格解码色度对照：15 项过、2 项失败（内置 FFmpeg VideoToolbox 与系统解码差异）。
- 长工程播放偶发 52–143 ms 时序离群点。
- 副屏、会议共享、移动设备（iOS/Android）实机验收：用户已明确延期，不算通过。
- 独立光标轨道（U30）、完整编辑器分区改造（U29）剩余部分。

### 2.3 许可与来源

- `next/cap/` 继承 Cap 0.6.0（固定提交 `6cfdd172…`），AGPLv3 及例外；修改与来源记录在 `next/cap/JIANKU-NOTICE.md`，发布时须提供对应源码与许可。
- 旧 Qt 版（`src/`、`ui/`、`CMakeLists.txt`）是历史实现，**不再是产品源码**；仅在追溯旧行为时参考。
- 应用标识 `com.jianku.screen.next`，工程后缀 `.jks`（兼容读取旧 `.cap`）。

### 4.2 常用命令（都在 `next/cap/` 下）

```sh
bun run jianku:setup       # 首次：bun install + 原生依赖 + Android 组件
bun run jianku:frontend    # 只重建前端
bun run jianku:check       # cargo fmt --check + cargo check -p cap-desktop
bun run jianku:build       # 调试包
node scripts/jianku.mjs release   # 发布包（= bun run tauri:build）
node scripts/jianku.mjs sign      # 只对已构建 bundle 补签并严格验证
node scripts/jianku-install.mjs --check                 # 预演安装
node scripts/jianku-install.mjs --source <app 路径>     # 安装（应用必须先正常退出）
node scripts/jianku-unattended-check.mjs                # 无人值守验证
node scripts/jianku-localization-audit.mjs              # 中文扫描
node scripts/jianku.mjs config darwin                   # 查看实际打包配置
```

### 4.3 一个阶段包的标准闭环（照做，不要跳步）

1. 队列里选定任务 → 读相关源码与上一条证据 → 复现/确认失败面。
2. 改源码 → 窄范围检查（`cargo fmt` + `cargo check -p <crate>`；前端 `biome check --write <files>`）。
3. 冻结提交 → 打 `next-v0.2.0-alpha.N-candidate` 标签（候选包用 `-candidate`，正式阶段包才用裸版本号）。
4. `node scripts/jianku.mjs release`，确认退出 0 且只有**一个** release 进程。
5. 严格验签：源 bundle、归档副本、暂存副本、安装后应用，四处一致；核对**六个可执行文件**的哈希；版本号 `0.2.0-alpha.N` / `2026.N.0`。
6. 用户正常退出当前应用 → `jianku-install.mjs` 安装 → 保留上一版 `previous.app` 作为回滚。
7. 用**自有合成工程**实际打开、操作、保存重开、导出并解码核对；把结果写进 `next/verification/YYYY-MM-DD-<topic>/README.md`（必要时附 json/帧图）。
8. 更新 `queue.md`（勾选/新增子项）、写 `session-YYYYMMDD-<topic>.md`、提交并推送 origin。

### 4.4 版本号与标签

- `CFBundleShortVersionString`：`0.2.0-alpha.N`；`CFBundleVersion`：`2026.N.0`（必须是 1–3 段数字，四段会被系统忽略，脚本会拒绝）。
- 候选标签：`next-v0.2.0-alpha.N-candidate`；稳定/阶段标签：`next-v0.2.0-alpha.N`。
- 冻结提交后不要再改源码；要改就新开提交并重新打包，不能“就地覆盖旧归档”。

### 4.5 权限（TCC）注意

- 一定从**访达或 Dock** 启动验收；从终端启动会把屏幕录制权限记在终端名下。
- 重编译/重签名会改变签名，可能需要重新授权；这是预期行为，不要把它当产品缺陷。
- 同步诊断需要屏幕录制权限；alpha.87/88 的实测均为 `denied`（TCC 无条目），alpha.88 起会跳过同步测试并给出中文提示。授权后需重启应用。

## 8. 工作约定（必须遵守）

以下来自根 `AGENTS.md` 与 `next/cap/AGENTS.md`，是硬约束：

1. **队列唯一真源**：`.dsh/unattended/queue.md`；每个任务必须“实现→验证→提交→记账”，大任务拆成可独立验证的子项。
2. **不虚报**：编译通过、组件测试、合成素材检查都不能写成“实机通过”；失败就保留失败记录并说明范围。
3. **证据规范**：`next/verification/YYYY-MM-DD-<topic>/README.md`，写清版本、冻结提交、操作、范围、结果、未覆盖项；敏感信息不入证据。
4. **用户素材与工程**：不读取、不上传、不修改真实用户录制；验收用自有合成工程与合成语音。清理只动确认属于本项目的可再生缓存/测试输出/旧构建，保留当前与上一版应用、工程、素材、Git 元数据与原生依赖。
5. **桌面与设备**：用户可能在用电脑；安装前确认应用已退出，不抢焦点、不强制弹窗；锁屏不绕过。不停止 Android 上的 VPN Hotspot/NekoBox，不改网络与设备设置。
6. **Git**：可向已有 `origin` 推送普通提交与回滚标签；**不得改写远端历史**，不擅自公开发布、不新增收费资源。
7. **不启动额外开发服务器**（`bun run dev*`、Docker 服务）；假定环境已就绪。
8. **代码风格**：Rust 按 `next/cap/AGENTS.md` 的零容忍清单（clippy `-D warnings`）；TS 用 tab + 双引号，Biome 检查；默认不写注释，只在修 bug/复杂取舍处写非显然原因。
9. **生成文件不要手改**：`**/tauri.ts`、`src-tauri/gen/**`、`auto-imports.d.ts`、Drizzle 迁移 SQL；改 Rust 后按流程重新生成并一起提交。
10. **额度与 goal 条款**：`AGENTS.md` 中 `get_goal`/`create_goal`/automation 相关规则是原 Codex 工具专用；换到其他工具时不要虚构这些接口。额度状态以实际读取为准，不凭只读工具声称已消费重置券。
11. **子代理**：允许用子代理做重复测试，主代理负责验收、提交与最终证据；避免多个代理同时改同一文件。

## 11. 术语表

- **alpha.N / 2026.N.0**：阶段包版本；`-candidate` 标签表示候选，安装后才是当前版。
- **冻结提交**：打标签时的提交，之后不再改；重建必须新提交。
- **六 hash / 六程序**：应用包内六个可执行文件的哈希，用于核对源/归档/暂存/安装一致。
- **journal / previous.app**：安装脚本留下的回滚副本；当前是 alpha.86。
- **`.jks` / `.cap`**：本产品工程后缀 / 旧 Cap 工程后缀（兼容读取）。
- **主轨磁吸 vs 吸附**：前者决定空隙是否收拢，后者只决定拖动时对齐；两个独立开关。
- **切片（slice）**：自动缩放在跨切点/重复素材后按来源拆出的独立区间，保留原弹簧相位。
- **全屏文字暂停窗**：文字全屏时冻结画面的时间段，参与输出时间映射。
- **U 编号**：队列任务号；父项不因部分子项完成而勾选。
