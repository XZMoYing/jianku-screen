## 2026-10-25 alpha.33：内边距示例缩放显示节奏

承接用户反馈，仅针对当前“内边距合成示例”核对，不假定其他工程同样失败或已经通过。原生持续产出约 60 帧仍可出现显示间隔拉长；原先的顺序队列没有时间戳调度，带行填充的像素又在异步整理回调中直接显示。现将该整理放在编辑器刷新回调内，按视频时间戳加入短缓冲，保留小幅漏帧之前的队列。缓存最多 4 帧，跳转、暂停、尺寸变化和长时间未到帧后重置；演示/首页维持原有最新帧策略。

## 本阶段交付范围

1. 可靠性：先定位并处理特定安卓设备的静止尾段时长缺失，核对真实录制计时、原始媒体、工程和导出时长；同时保留 alpha.25 暂停回退播放、画面继承及现有核心流程回归。
2. 录制书签：电脑 Studio 录制中可从录制条添加书签，并在快捷键设置中配置操作；书签按录制媒体时钟保存，暂停时间不计入。编辑器可列出、命名、跳转和删除书签；剪切、重排和变速后通过源片段坐标映射，不把旧墙钟时间直接放到新时间线。
3. 演示幕布：演示过程中可暂时遮盖观众输出并恢复，提供清晰状态与可配置快捷操作，操作者主屏保持正常。新会话从正常输出开始；退出和重启不带入上次的临时遮盖状态。输出窗口、后台帧与副屏显示需要共同验证。

书签与幕布优先复用现有热键、工程存储、时间线和输出路径。媒体的光标、缩放、阴影和动态模糊效果保持。自动识别敏感信息、完整视频回放、在线账户和 Windows 适配不属于本阶段交付。
