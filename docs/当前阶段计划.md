## 2026-10-25 窗口录制范围选择

用户明确要求保留其他窗口遮挡所选窗口时也能入镜的效果，不能把它作为必须移除的行为。当前阶段增加“过滤其他窗口”开关，默认关闭并记住选择：关闭时继续录制窗口所在的显示器区域，开启时使用独立窗口采集。电脑 Studio 与即时录制读取同一设置，并在暂停/恢复及采集重启时保持选择。

独立窗口模式需要核对遮挡、移动、改变比例和光标坐标；普通区域模式需要确认遮挡内容仍然保留。实际成片与当前应用验证通过后才更新交付状态。Android 静止尾段、动态背景与播放稳定性以及其他队列保持后续安排，不将增加开关视为这些问题已经解决。

alpha.27 优化版已安装、打开并归档，窗口选择开关的实际录制和坐标对照已通过。用户于 2026-10-25 恢复开发授权：后续先处理 Android 静止尾段缺失，再推进预览与导出剩余性能项，保持画质与视觉效果。

## 本阶段交付范围

1. 可靠性：先定位并处理特定安卓设备的静止尾段时长缺失，核对真实录制计时、原始媒体、工程和导出时长；同时保留 alpha.25 暂停回退播放、画面继承及现有核心流程回归。
2. 录制书签：电脑 Studio 录制中可从录制条添加书签，并在快捷键设置中配置操作；书签按录制媒体时钟保存，暂停时间不计入。编辑器可列出、命名、跳转和删除书签；剪切、重排和变速后通过源片段坐标映射，不把旧墙钟时间直接放到新时间线。
3. 演示幕布：演示过程中可暂时遮盖观众输出并恢复，提供清晰状态与可配置快捷操作，操作者主屏保持正常。新会话从正常输出开始；退出和重启不带入上次的临时遮盖状态。输出窗口、后台帧与副屏显示需要共同验证。

书签与幕布优先复用现有热键、工程存储、时间线和输出路径。媒体的光标、缩放、阴影和动态模糊效果保持。自动识别敏感信息、完整视频回放、在线账户和 Windows 适配不属于本阶段交付。
