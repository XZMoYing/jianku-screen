# 简库镜传 Next 构建入口

在next/cap目录使用以下入口。版本号与Mac bundleVersion仍在apps/desktop/src-tauri/tauri.jianku.conf.json维护；Mac额外的采集程序／资源和框架在tauri.jianku.macos.json。构建脚本合并这两层，Tauri再合并基础与自动生成的平台依赖清单。

| 操作 | 命令 | 范围 |
| --- | --- | --- |
| 查看本机配置 | `node scripts/jianku.mjs config` | 只读显示平台、包类型和产品覆盖配置 |
| 查看其他平台清单 | `node scripts/jianku.mjs config win32` 或 `config linux` | 只检查配置，不跨平台编译 |
| 原生检查 | `node scripts/jianku.mjs check` | 本机平台配置与编译检查 |
| 调试包 | `node scripts/jianku.mjs build` | 生成本机平台调试包 |
| 优化包 | `node scripts/jianku.mjs release` | 生成本机平台优化包 |
| 无人值守基线 | `node scripts/jianku-unattended-check.mjs` | 使用相同平台配置的局部基线，不能代表发布审计 |

| 平台 | 当前包类型 | 辅助程序 |
| --- | --- | --- |
| macOS | app | 三项通用程序，加iOS／安卓采集组件 |
| Windows | nsis | 三项通用程序 |
| Linux | deb | 三项通用程序 |

配置拆分已消除非Mac清单无条件要求未生成移动程序的问题。Mac合并结果与alpha.63旧完整清单逐项相等，实际Mac编译检查通过。Windows/Linux仍需要在对应环境完成依赖安装、编译、打包、安装与功能验收；config命令输出不是目标平台支持证明。移动录制的目标平台实现、路径和可用性提示也需继续适配。

基础配置中的内置背景／音乐资源及产品许可通过对象合并保留，辅助程序数组按Tauri合并语义整体替换。当前CI生产发布配置是另一入口，尚未据此宣称简库三平台构建成功。证据next/verification/2026-11-06-platform-config/；完整能力／平台差距见research/2026-11-06-Windows-Linux构建入口盘点.md。
