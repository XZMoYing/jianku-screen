## 默认关联

| 对象 | 默认关系 | 变速与时长 |
| --- | --- | --- |
| 视频原声 | 随对应视频实例 | 延续静音／保持音高／随速度变化规则 |
| 自动缩放、原始按键、由原声生成的字幕 | 随来源画面 | 按源时间映射，切片／重复使用分别对应实例 |
| 手动2D／3D镜头、文字／图片／遮罩 | 新建时优先关联已选择的片段；无明确目标则留在时间线 | 默认保持自身动画时长，可明确选择随片段变速 |
| 配乐 | 保持时间位置 | 保持音频自身时长，提供关联到片段的选择 |
| 全局背景、留白、外框与阴影设置 | 全局画面 | 不因单个视频重排而重排全局设置 |
| 独立光标轨道（后置U30） | 随来源视频实例，可手动偏移 | 原始事件不破坏，保留偏移提示与自动对齐 |

旧工程缺少可靠来源时不能随便把所有覆盖物绑定给某一个片段。先依据实际源数据／模式建立能证明的对应关系；跨片段的自动内容按切点拆映射并保持现有曲线相位。没有明确来源的手动内容保留当前画面与时序，并显示可理解的关联状态，用户可选择关联对象。素材来自同一文件不意味着同一实例。

## 用户操作

选中对象时，用小图标和片段名说明关联，菜单提供“随片段移动”“保持时间位置”“关联到当前片段”。切换关联本身保持当前画面和位置；只有后续剪辑才按新关系联动。不要切换开关就把画面跳到别处，也不强制弹出向导。脱离关联保留当前输出位置；重新关联先按当前位置换算，整次操作可撤销。

主轨磁吸控制空隙／插入／删除／排序，自动吸附只控制拖动时对齐；各自有独立、可记住的状态。关闭磁吸后的空隙须进入真实工程模型并在预览与导出一致显示，不放只有视觉作用的开关。指针越过小幅阈值再开始拖动，插入标记跟随最终意图，松手一次提交；Escape／失焦／来源消失取消，不产生错误移动。

重排、修剪、删除和变速复用同一命令和实例映射；每次用户动作只有一条历史。仍存在的选择随实例保持，删除的实例不把选择悄悄交给同一数组位置的新片段。播放头与时间线缩放／滚动保持用户当前观看位置；不因改值重放整页面进场。

## 时间域与动画

映射区分源文件时间、视频实例的编辑范围，以及含转场／全屏文字暂停的输出时间。全屏文字的暂停时长独立，关联的是来源位置；先重算暂停窗口，再映射其余源相关内容，避免只给起点加减秒数。切点上的连接对象明确归属于一个实例，不能在两侧移动时来回换主。

手动镜头的关键帧按既定求解器求值，切片保留轨迹／弹簧相位；不重新套一段普通缓动把速度清零。转场改动须保留原邻接对的意义，不把旧转场随数组序号交给无关片段。源相关对象与固定时间对象分别按其显式关系处理。

不能把错位藏起来：来源缺失、超出片段范围和人为时间偏移分开说明。U30光标任何形状／显隐／数值差异的过渡、热点对齐及确定性跳播要求继续按product/requirements/editor-workflow.json实现；漂亮的过渡不会清除未对齐标志。
