# 简库镜传 Next｜首个正式版发布计划

更新：2026-10-27。当前安装版本 alpha.37；本文件定义首版收尾建议与验收门槛，不代表已完成发布审计。

## 发布判断

完整中文、本土化和审计通过都是必要条件。正式发布还需要核心使用闭环可靠、关键视觉效果验收、安装分发完整，以及对外承诺功能的实际验证。当前仍处于收尾阶段，无法根据 alpha 编号给出可信的固定日期。

按三个阶段推进：稳定性与正确性 → 完整中文与发布审计 → RC 候选版验收。每阶段以剩余问题和可复验证据判断完成；发现阻塞缺陷时修复并复测。第一阶段收尾并完成首次审计后，再依据剩余缺陷给出日期估算。

## 首版范围建议

首版以 macOS 已实现的录屏、编辑、导出、截图和实时演示为主体。主屏操作保持正常、观众输出的平滑与焦点控制，以及预览/导出画面质量属于核心体验；不以降低视觉效果换取通过。

移动录制、副屏与会议共享的物理验收仍按用户要求顺延。在对应验收完成前，这些能力不能宣称已稳定交付；进入正式功能介绍前需完成对应闭环，或由用户明确决定以测试功能提供。当前继续其他开发，不要求连接设备，也不擅自隐藏或删除已有功能。

2026-10-27 用户扩大本轮范围：继续推进 Windows、Linux 适配，先形成平台能力与依赖矩阵，再逐平台编译和运行验收；仅有共享代码或条件编译不能宣称支持。macOS 当前体验与完整视觉效果仍须保持，缺少目标系统环境的项目明确记录待验证。在线账户保持“敬请期待”，本地流程应完整可用。新增功能与参考软件的完整功能台账继续保留，不自动变为首版已完成事项。原有动画匹配硬性目标保持，现阶段不宣称所有场景已经百分之百一致；公开产品文案使用本产品名称和功能描述。

长 GOP 首次定位仍需改进，已撤回收益不稳定的试验。优先解决明确错误和连续操作中的停顿；单个耗时指标须使用相同素材与正确画面对照，并记录取消、内存和回退行为。

| 品牌和外部入口 | 新录制默认名称、窗口/菜单/通知及应用资源使用本产品名称；未上线账户/云功能明确提示，不跳转上游服务器。原始许可、第三方归属和源码信息单独保留。 |

审计需产出“检查了什么、发现什么、如何处理、哪些尚未验证”的报告。自动检查通过与代码审阅分别记账；内部审计不能表述为第三方安全认证。

## 阶段三：RC 与公开发布

1. 从明确的 Git 提交生成候选包；核对实际运行路径、版本/构建号和源包/安装包指纹，完成发布渠道要求的正式签名和公证。当前 ad-hoc 包继续用于开发试用。
2. 在声明支持的 macOS 与硬件范围验证首次安装、授权、录制/编辑/截图/演示/导出、工程关联、升级和回滚；对外标为稳定的物理设备/共享场景需实际验证。
3. 完成中文逐页走查和连续使用，确认无未关闭的阻塞缺陷或数据损坏问题；审计中的高严重性问题完成修复或有用户明确接受的处理决定。
4. 保存安装包、对应源码/许可、更新说明、已知限制和恢复方法。由用户决定公开发布时间和发布动作。

详细缺陷、历史证据和物理验收统一维护在 [待验证项目交接](待验证项目交接.md)，本文件只定义发布顺序与门槛。
