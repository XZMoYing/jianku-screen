## 阶段顺序与完成定义

1. 时间线主片段与真实媒体：片段选择/裁剪/重排/变速、缩略图、波形、缩放/滚动/吸附；工程格式兼容、源视频解码和音轨映射一并通过。
2. 可编辑焦点与效果：独立焦点轨、手动构图、复制/粘贴、统一历史与保存、效果边界吸附；保留现有动画解算器。
3. 画面内容与摄像头：裁切、贴图/遮挡/柔化、高亮、摄像头采集/布局/同步/运动、开场和场景预设。
4. 音频、字幕与工作流：逐片段声音、音乐/点击音、字幕/快捷键、标记/备注、导入/导出/分享和工作区细节。
5. 受控参考视觉验收与实时输出：逐帧对齐、动态模糊、录制/演示共同参数、多屏与会议实机验收。

当前编辑记录保存为 `jianku-edit/4`：统一存储主片段、焦点、裁切/外观和保存时的播放头；可读旧版 `/1`、`/2`、`/3`。每次替换前将完整旧记录保存为 `edit.previous.json`，原始媒体不改写。0.1.1–0.1.3 不识别 `/4`，试用使用新的隔离副本，避免旧版覆盖新版记录。上一版备份是本地恢复素材，当前没有一键恢复界面。

阶段结束仅表示该阶段通过，不表示完整功能目标达成。每阶段记录实测证据、遗漏和实际打开的应用；用户试用期间继续整理下一阶段，不代替用户作出体验验收。
