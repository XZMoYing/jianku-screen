## 当前仍开放的主要验收门槛（不满足正式公开发布）

1. **屏幕录制权限与同步实测（U10b3b3）**：需用户在系统隐私中授予本应用屏幕录制权限并重启后，采集内置音画同步五项实测数值。
2. **严格解码色度边界（U11a3 / U19d2）**：色彩契约核心（BT.709 limited 与 NV12 附件）已合入并关闭 U11a/U11a2；内置 FFmpeg VideoToolbox 解码色度差异与零阴影 MP4 偶发运行间差异仍待归因。
3. **长工程播放时序**：10/30/60 分钟抽样存在偶发 52–143 ms 离群点，尚未关闭。
4. **编辑器交互与工作流剩余项（U22 / U23 / U24 / U25b / U29 / U30）**：原生包逐轨连续拖动与逐键内容复验、冷启动携工程文件全入口覆盖、U29 剩余命令/吸附/关联与排在其后的 U30 独立光标轨道。
5. **跨平台与延期实机**：Windows/Linux 仅完成源码入口与矩阵审计，未在目标平台构建运行；副屏、会议共享、iOS/Android 移动录制实机验收按用户要求延期，不标为通过。
6. **主观视觉与观感确认**：3D 运镜舒适度、界面动效观感与完整逐帧动画对照需用户最终确认。
