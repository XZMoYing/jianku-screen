## 2026-10-12 第二阶段 C：目标时间与停止收尾（0.2.0-alpha.4）

普通光标目标取消通用未来预读，保留点击前瞻；每步先推进旧目标，再设置当前目标与条件参数，保持速度。采样时间由整数序号换算，避免逐步相加带来的事件边界误差。位置仍使用上游解析求解器、UV 单位和输入过滤，未将它说成已经完整替换为参考模型。

位置缓存不再在末次移动后 300 毫秒截断：覆盖最后移动与点击后继续收敛；对 20 秒内仍不静止的参数，用最终状态和原有解析求解器按查询时刻继续计算，保留有界缓存与可反复定位。原始模式、相机和画面参数保持。

已复现旧版操作前抢先移动、原生 GPU 帧偏移及收尾冻结；修改后通过独立 181 步解析轨迹、默认收敛/晚到点击/无阻尼继续运动、反向定位与直接/缓存一致检查。原生 GPU 还覆盖剪切重排、0.5×/2×、30/60/120 fps 和两种输出尺寸；这只验证项目内部一致性，没有替代参考应用逐帧对照。

## 2026-10-12 第二阶段 B：偏侧缩回与平移模糊（0.2.0-alpha.3）

缩回时不再因两帧画面存在包含关系就将模糊中心放到旧画面中间，改为先求对应角点运动线交点。边角焦点的测试进一步暴露了静止角点的浮点误差，现按坐标与方向的尺度排除退化线段，并使用另一组角点；平行线或无有效交点的回退保留。画面与摄像头共用中心选取，场景切换的合成缩放模糊仍保留。

画面和光标的平移模糊均保留 21 次取样，按已有参考研究校准为中心一份，再叠加 `0/20..19/20`；保持原有强度、帧率归一化、透明度和边缘处理。测试用自建渐变在原生 Metal 测量四个方向的拖影重心，并检查透明光标拖影，修改前失败、修改后通过；几何焦点、编辑图层、布局和上一阶段光标回归亦通过。没有修改位置平滑、相机弹簧、画面搭配或 3D 参数。

48 项不同的相关测试通过，最终调试应用编译、打包及严格签名检查通过。固定自建背景的两个版本均实际导出 6 秒、1280×800 / 60 fps / 360 帧，并通过完整解码；关闭模糊后每帧 RGBA 与时间戳完全一致，开启后 268 帧发生预期的模糊变化。该比较仅为 alpha.2 与 alpha.3，不是参考应用的像素验收。

alpha.2 正常退出后已打开 alpha.3（PID 65623），保留旧应用和工程，载入偏侧缩放样例；原生窗口和日志确认编辑器打开、帧送达，并观察到短合成工程的播放。正式版、长工程及实际显示帧率仍需单独测量。打包、实际导出及启动结果记录在 [本阶段验证](../next/verification/2026-10-12-motion-blur/verification.json)。全套参考输出、中心限幅、无交点行为、父子运动和缩放取样链仍按 [待验证项目交接](待验证项目交接.md) 验收；不能据本阶段局部检查宣称百分之百一致。

## 2026-10-12 第二阶段 A：光标倾斜与点击形变（0.2.0-alpha.2）

光标倾斜改为读取目标轨迹的 400 毫秒横向变化，先限幅，再交给条件弹簧；普通移动、接近点击和拖动切换参数时保留速度。复用旧版自行实现并核对过的毫秒积分、相对精度和逐帧更新顺序，移植为独立 Rust 模块。倾斜幅度使用原始录制宽度，避免随预览或导出分辨率改变。

点击形变改用 300/30/0.3 的独立弹簧，130 毫秒是按下前瞻窗口，释放后不再用固定时长强制回到原大小。连续点击和多个鼠标键交叠时保持当前状态与速度。预览和导出共用姿态计算，每个光标时间线最多缓存两套设置；原始模式仍缓存点击动画，避免每次预览从头计算。

位置平滑、原始位置的时间补偿、去抖、镜头、3D 运镜、闲置隐藏、阴影与模糊仍沿用 Cap。本阶段没有完成全部动画替换；帧率采样、目标事件规则、Retina 坐标单位、长工程、参数连续调整以及官方受控导出的逐帧对照仍按交接清单推进。样例工程将旋转量设为 0.5 便于观察，没有更改产品默认的 0.15。

### 已实现并验证

### 这一夜修掉的真实缺陷

按「查出来的根因」记，不按改动大小记：

1. **暂停后停止会产出没有 moov 的坏 MP4。** 暂停折叠时钟被减了两次，末帧 PTS 算成
   负 1829 秒，`AVAssetWriter` 直接拒绝写入。用坏文件里的真实时间戳把算式重算了一遍
   才定位到，单测里把旧表达式钉成负向对照。
2. **`project.json` 里 `microphone` 字段一直是 `true`。** `NSDictionary` 交给
   `QJsonValue` 时重载解析落到了指针转 bool——文件名与时长从来没被保存过。
3. **`-shortest` 会把成片静默裁短。** 7480 帧只写出 7470 帧还报成功。加了成片回读校验。
4. **全片导出被内核 OOM 杀掉。** `QProcess` 写缓冲无上限，RSS 涨到 82GB 触发
   low-swap killer。加背压后稳定在 284MB。
5. **窗口来源默认带阴影会内缩 64px。** 实测：含阴影时内容从 (64,49) px 才开始不透明，
   帧尺寸却仍是窗口尺寸。不关阴影则窗口录制里每个指针事件都偏。
6. **`cursorSmoothing` / `clickEffect` 写了没人读**，UI 上是假开关。

## 动画引擎（2026-10-03 自驱推进，历史记录）

按"先核对、再实现、后对照"推进，核心已在 C++ 中实现并有单元测试。

- **D1 求解器已逐字核对并实现**：从官方包反混淆还原半隐式 Euler、`ceil(dt)` + `i - dt` 分数尾步、目标变更保速与缓存精度、`settleTime` 估算（0→1000，步长 1000/60，上限 20000ms）、`mass==0` 吸附。见 [弹簧求解器核对](../research/弹簧求解器-官方包核对.md) 与 `src/animation/SpringSolver.{h,cpp}`。
- **D2 指针姿态引擎**：事件模型、500ms 点击前瞻目标、条件弹簧（关闭 1/1/0、临近点击 530/40/1、拖拽 1000/40/1、默认 470/70/3）、旋转（400ms 窗口 × 0.03，clamp ±20°）、点击缩放（130ms 前瞻）、静止隐藏（250ms 恢复）。见 [指针链路核对](../research/指针链路-核对.md) 与 `src/animation/CursorEngine.{h,cpp}`。
- **D3 自动焦点**：区间生成（复用已验证规则）+ 区间内事件贪心分组（组尺寸 = 内容/倍率 ×(0.5,0.7)）+ 包围盒中心 + 相机变换（边缘映射与覆盖夹紧）。见 `src/animation/AutoFocusEngine.{h,cpp}`。
- **D4 动态模糊（历史）**：当时写在 `src/animation/MotionBlur.{h,cpp}`，实测放大闪烁、平移花屏后**已整体删除**。2026-10-04 以离线逐帧的方式重做，新实现在 `src/render/MotionBlur.{h,cpp}`，参数规则相同但不受实时状态影响。
- **D5 实时接入（首版）**：`AnimationDriver` 轮询系统指针（无需采集权限）→ 指针引擎 → 预览叠加平滑指针；点击触发因果放大，相机由画面弹簧驱动；预览内容层应用相机缩放/位移。见 `src/animation/AnimationDriver.{h,cpp}`、`src/mac/MousePoll.mm`、`ui/PreviewCanvas.qml`。
