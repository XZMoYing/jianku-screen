## 2026-10-25 动态模糊中心与内外框坐标（alpha.34）

alpha.33 的用户回测仍不通过，反馈更接近“画面或内框来回晃”。进一步验证显示，原始彩色素材的静止分界线在合成视频中也会回摆；静止标记的原生 Metal 输出与 CPU 几何共同定位到模糊中心计算。接近对角线焦点时，相对角点轨迹近共线，浮点误差被交点求解放大；原实现偶发得到错误的右下角中心。坐标求解现在使用缩放的固定点，避免该病态；纯位移和退化轴仍使用有限回退。外框的 UV 中心与位移向量转换到与内容/内框相同的输出像素坐标。

原版确定性测试在实际 1248×702、帧 61 即失败，原始错误记录保留。静止标记放大/缩小原来分别有 4 次超过 0.2 像素的反向跳动，最大约 4.35/3.42 像素；修复后均为零。目标尺寸、位置、缩放和模糊强度逐帧相同，14 组关闭模糊的完整帧像素一致。修复不更改弹簧参数、曲线、模糊采样核、预览分辨率或显示队列；应用、演示和 CLI 共用同一内核。证据及后续交付见 [alpha.34 记录](../next/verification/2026-10-25-alpha34-blur-pivot/README.md)。

重新构建的优化 CLI 对原四段彩色示例导出通过，放大期间静止分界线的波动由约 6.77 像素降至约 0.061 像素；此为编码视频位置分析，不代替物理显示或主观验收。

### 这一夜修掉的真实缺陷

按「查出来的根因」记，不按改动大小记：

1. **暂停后停止会产出没有 moov 的坏 MP4。** 暂停折叠时钟被减了两次，末帧 PTS 算成
   负 1829 秒，`AVAssetWriter` 直接拒绝写入。用坏文件里的真实时间戳把算式重算了一遍
   才定位到，单测里把旧表达式钉成负向对照。
2. **`project.json` 里 `microphone` 字段一直是 `true`。** `NSDictionary` 交给
   `QJsonValue` 时重载解析落到了指针转 bool——文件名与时长从来没被保存过。
3. **`-shortest` 会把成片静默裁短。** 7480 帧只写出 7470 帧还报成功。加了成片回读校验。
4. **全片导出被内核 OOM 杀掉。** `QProcess` 写缓冲无上限，RSS 涨到 82GB 触发
   low-swap killer。加背压后稳定在 284MB。
5. **窗口来源默认带阴影会内缩 64px。** 实测：含阴影时内容从 (64,49) px 才开始不透明，
   帧尺寸却仍是窗口尺寸。不关阴影则窗口录制里每个指针事件都偏。
6. **`cursorSmoothing` / `clickEffect` 写了没人读**，UI 上是假开关。

## 动画引擎（2026-10-03 自驱推进，历史记录）

按"先核对、再实现、后对照"推进，核心已在 C++ 中实现并有单元测试。

- **D1 求解器已逐字核对并实现**：从官方包反混淆还原半隐式 Euler、`ceil(dt)` + `i - dt` 分数尾步、目标变更保速与缓存精度、`settleTime` 估算（0→1000，步长 1000/60，上限 20000ms）、`mass==0` 吸附。见 [弹簧求解器核对](../research/弹簧求解器-官方包核对.md) 与 `src/animation/SpringSolver.{h,cpp}`。
- **D2 指针姿态引擎**：事件模型、500ms 点击前瞻目标、条件弹簧（关闭 1/1/0、临近点击 530/40/1、拖拽 1000/40/1、默认 470/70/3）、旋转（400ms 窗口 × 0.03，clamp ±20°）、点击缩放（130ms 前瞻）、静止隐藏（250ms 恢复）。见 [指针链路核对](../research/指针链路-核对.md) 与 `src/animation/CursorEngine.{h,cpp}`。
- **D3 自动焦点**：区间生成（复用已验证规则）+ 区间内事件贪心分组（组尺寸 = 内容/倍率 ×(0.5,0.7)）+ 包围盒中心 + 相机变换（边缘映射与覆盖夹紧）。见 `src/animation/AutoFocusEngine.{h,cpp}`。
- **D4 动态模糊（历史）**：当时写在 `src/animation/MotionBlur.{h,cpp}`，实测放大闪烁、平移花屏后**已整体删除**。2026-10-04 以离线逐帧的方式重做，新实现在 `src/render/MotionBlur.{h,cpp}`，参数规则相同但不受实时状态影响。
- **D5 实时接入（首版）**：`AnimationDriver` 轮询系统指针（无需采集权限）→ 指针引擎 → 预览叠加平滑指针；点击触发因果放大，相机由画面弹簧驱动；预览内容层应用相机缩放/位移。见 `src/animation/AnimationDriver.{h,cpp}`、`src/mac/MousePoll.mm`、`ui/PreviewCanvas.qml`。

测试：`ctest` 4 组全通过（timeline-boundaries、spring-solver、cursor-engine、auto-focus）。
