## 2026-10-11 完整编辑器：第二阶段（0.1.3）

- 新增独立自动/手动焦点轨道：自动区间可选择、移动、裁剪、拆分、禁用、删除和重建；手动区间可在空白处拖动创建或在播放头添加，支持固定位置/跟随操作、倍率、位置、边缘吸附。
- 焦点检查器随选择切换；暂停时可预览目标构图，通过位置面板或画布点击定位。目标构图用于编辑，实际播放和导出仍运行现有弹簧、指针和动态模糊求解器。
- 复制/粘贴使用系统剪贴板；支持在播放头或右键位置创建副本、仅粘贴属性。区间可吸附主片段/焦点边界/播放头，同轨重叠和越过剪辑切点被拒绝。

- 主片段、焦点、全片外观共用撤销/重做；属性连续变化按相同字段、500 毫秒间隔合并。空闲 1 秒自动保存，关闭时补存未保存修改。保存前以原子写入保留 `edit.previous.json`。

## 2026-10-04 无人值守推进（阶段记录）

一夜之间把「录制成片」这条链路从「录到的是没有指针、没有镜头、没有包装的原始画面」
补到「可以直接导出成片」。全部改动在本地提交，`ctest` 10/10，构建 warning 归零。

### 已实现并验证

- **离线合成器** `jianku-compose`：ffmpeg 解码 → 逐帧合成 → libx264 编码 → 音频封装。
  用的是与预览**同一套** `SpringSolver` / `CursorEngine` / `AutoFocusEngine` /
  `CanvasLayout` / `driverSettingsFromMap()`，不是另写一份缓动。
  真实 124.66s 工程：3360×2100、7480 帧写入 / 7480 帧回读、h264+aac、完整解码无错。
- **指针与镜头进入成片**：`--no-cursor` 与默认输出的逐像素差分定位到指针像素，
  确认指针真的被画进去了而不是「应该画进去了」。
- **导出接进界面**：工具栏「导出成片」，工作线程 + 进度条 + 可取消，完成后在
  Finder 定位产物。
- **画布包装统一**：`src/render/CanvasLayout.{h,cpp}` 一条规则、纯函数，预览、截图与
  合成器共用；此前三处各算各的且互相不一致。
- **窗口与区域来源**：`src/capture/CaptureSource.{h,cpp}`，三种来源共用一条管线。
  窗口用 `initWithDesktopIndependentWindow`，区域用 `sourceRect`。
- **麦克风并入成片**：按录到的 host 时间戳对齐后混音；只有系统声音时仍走 `-c:a copy`
  不重编码。互相关确认对齐偏移 13.2 ms、相关系数 0.994。
- **动态模糊（离线）**：`src/render/MotionBlur.{h,cpp}`，纯函数，逐条对着 3.7.5 静态
  定位写（通道二选一、两个阈值、fps/60、kernel 21 单侧分布、kernel 13 权重 4(p−p²)、
  父层运动扣除）。

### 这一夜修掉的真实缺陷

按「查出来的根因」记，不按改动大小记：

1. **暂停后停止会产出没有 moov 的坏 MP4。** 暂停折叠时钟被减了两次，末帧 PTS 算成
   负 1829 秒，`AVAssetWriter` 直接拒绝写入。用坏文件里的真实时间戳把算式重算了一遍
   才定位到，单测里把旧表达式钉成负向对照。
2. **`project.json` 里 `microphone` 字段一直是 `true`。** `NSDictionary` 交给
   `QJsonValue` 时重载解析落到了指针转 bool——文件名与时长从来没被保存过。
3. **`-shortest` 会把成片静默裁短。** 7480 帧只写出 7470 帧还报成功。加了成片回读校验。
4. **全片导出被内核 OOM 杀掉。** `QProcess` 写缓冲无上限，RSS 涨到 82GB 触发
   low-swap killer。加背压后稳定在 284MB。
5. **窗口来源默认带阴影会内缩 64px。** 实测：含阴影时内容从 (64,49) px 才开始不透明，
   帧尺寸却仍是窗口尺寸。不关阴影则窗口录制里每个指针事件都偏。
6. **`cursorSmoothing` / `clickEffect` 写了没人读**，UI 上是假开关。
