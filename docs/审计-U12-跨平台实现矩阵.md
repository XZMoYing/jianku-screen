# U12 跨平台实现矩阵（审计快照，2026-11-08 / alpha.106 源码）

范围：next/cap 工作区（Tauri v2 + SolidStart 桌面端、Rust crates）。方法：源码走查条件编译与平台模块、依赖清单、现有验证记录。**本矩阵不代表 Windows/Linux 已构建或运行**；本仓库只在 macOS 14.7.4 (Apple Silicon) 实机构建与验证。

## 3. 新增功能（本 fork）与平台缺口

1. 主窗口普通化+置顶偏好、录制控制浮窗置顶、防遮挡层：NSPanel/窗口 API 强 mac 门控；Win/Linux 使用 tauri 通用窗口 fallback，未验证。
2. 编辑器窗口延迟显示（防冷启动白屏）：前端 reveal + Rust 兜底；窗口 API 跨平台，异常/多显示器场景未验证。
3. 编辑器窗口透明/HUD：mac 使用 HUD 效果；Win/Linux 为空或不同效果，未验证。
4. 权限引导、系统音频探测、壁纸背景、防遮挡：以 mac 实现为主。
5. 本地化：前端词典跨平台；窗口标题/原生菜单/系统对话框按钮依赖平台 API。
6. 诊断报告：系统探测按平台分支（sw_vers/system_profiler/glxinfo/systeminfo），Win/Linux 分支未实机验证。
7. 导出硬件/软件路径：macOS VideoToolbox 与 FFmpeg 已验证；Win/Linux 编码器与色彩标签未验证。

## 4. 目标环境要求

- 通用：Rust 1.88、bun 1.4、Tauri v2、FFmpeg 原生库（native-deps）、wgpu 后端。
- macOS：Xcode 16/macOS 14+、ScreenCaptureKit、VideoToolbox、Swift 桥、签名；TCC 屏幕录制/麦克风/辅助功能。
- Windows：MSVC/Windows SDK、Direct3D 11/12、MediaFoundation；NVENC/FFmpeg 可选；MSI/NSIS 打包与签名。
- Linux：X11/Wayland、PipeWire/PulseAudio、Vulkan/Mesa、VAAPI、GTK/WebKitGTK；AppImage/deb/rpm 与 portal 权限。

## 5. 结论与后续

- 实现矩阵已形成；Windows/Linux 未构建、未运行、未签名验证，U13-U16 需在目标环境进行。
- 优先：Windows 编译路径（U13/U14）与 Linux X11 编译路径（U15），每平台至少一次构建+启动+屏幕捕获/编辑/导出冒烟；非目标平台结果不得写成已支持。
- 不创建公开发布资源；仅保留可回滚的 macOS 试用包。

## 未覆盖
