# U09 内部审计：文件路径、外部进程与任务取消

审计日期：2026-11-08（alpha.104 源码）。范围：next/cap/crates/project、next/cap/crates/recording、next/cap/apps/desktop/src-tauri 中与工程文件、素材路径、外部进程、任务/子进程取消相关的路径。方法：源码走查 + 现有实际包验证结果引用。本审计不声称第三方认证或穷尽所有平台差异。

## 发现

| 编号 | 严重性 | 发现 | 证据 |
| --- | --- | --- | --- |
| F1 | 中（隐私） | 便携副本会把工程配置里引用的任意可读外部文件复制进副本：AssetCopier::materialize 对外部路径 canonicalize 后直接 copy_file_checked 到 assets/portable/<uuid>/，并重写配置为相对路径；无外部素材清单或确认。构造/打开的不可信 .jks 可引用 ~/.ssh/id_rsa 等文件，用户执行「保存可携带副本」后该文件会进入待分发副本。 | crates/project/src/portable.rs:222-269；实测：外置素材便携副本把 external-asset.png 复制进 assets/portable/<uuid>/（next/verification/2026-11-08-portable-external-asset） |
| F2 | 低 | resolve_project_asset_path 仅做字符串替换后 project.join(clean)，不拒绝 .. 等穿越片段；越界路径在 F1 中被当作“外部素材”处理。 | crates/project/src/portable.rs:21-27 |
| F3 | 信息 | 生产代码的外部进程调用均为固定二进制 + 参数数组，无 shell 拼接：sw_vers、system_profiler、pactl、glxinfo（诊断/系统探测，只读），以及 cap-muxer 子进程（Command::new(&bin_path)，参数经 configure_muxer_command）。未发现命令注入路径。 | crates/recording/src/diagnostics.rs、sources/screen_capture/linux.rs、output_pipeline/oop_muxer.rs:181-200 |
| F4 | 信息 | MuxerSubprocess 的 Drop 在子进程仍运行时 kill+wait；finish/reap 路径也显式 kill+wait；stderr 读取线程独立，取消/丢弃不会遗留僵尸 ffmpeg。 | crates/recording/src/output_pipeline/oop_muxer.rs:567-585、:489-505 |
| F5 | 低 | copy_file_checked 在复制前后比较大小与 mtime 检测并发写，但 canonicalize 与复制之间存在 TOCTOU 窗口（符号链接替换/文件被替换）；失败会报错而非静默继续。 | crates/project/src/portable.rs:272-288 |

## 结论与建议

- F1/F2 归为同一隐私风险：建议在「保存可携带副本」前扫描配置中的外部素材路径并列出确认（或提供“仅复制工程内素材”选项）；长期可要求外部素材来自文件选择器并记录来源根目录，而不是信任配置中的任意路径。
- F3/F4 未发现需立即修复的问题；保留为审计记录。
- F5 为低概率竞态；现有报错+用户重试策略可接受。
