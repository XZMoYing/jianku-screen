# 字幕 SRT 导出实际包验收（alpha.91）

安装版 0.2.0-alpha.91／2026.91.0。在自有合成工程（4 条录音字幕）上通过编辑器「字幕」面板与原生保存对话框导出 SRT，核对文件格式与内容，并在真实拖动修改字幕计时后再次导出，确认导出使用编辑后的时间线而非旧数据。

## 操作路径

1. 打开工程 → 头部「字幕」按钮进入字幕面板（AX 可见「添加」「SRT」「VTT」按钮）。
2. 点击 SRT → 出现原生保存面板（AXSheet，AxTextField 预填 `字幕导出验收.srt`，按钮 Cancel／Save）。
3. AXPress Save 保存；再次导出时用 AX 设置文件名 `字幕导出验收-编辑后.srt`。
4. 用真实鼠标拖动第 3 条字幕到 5.157–6.747 并保存（母版与派生轨道一致，U25b1 已修），再进入字幕面板导出第二份。
5. 直接读取两个 SRT 文件核对。

## 结果

基线 SRT（`字幕导出验收.srt`，229 字节）：

```
1
00:00:00,000 --> 00:00:01,790
Synthetic Cobalt Lantern

2
00:00:02,090 --> 00:00:04,920
This is an offline diagnostic test.

3
00:00:04,920 --> 00:00:06,510
Synthetic Cobalt Lantern

4
00:00:07,370 --> 00:00:08,000
BLANK_AUDIO
```

编辑后 SRT（`字幕导出验收-编辑后.srt`）：第 3 条变为 `00:00:05,157 --> 00:00:06,747`，其余三条不变。说明导出读取当前编辑后的字幕计时，而不是缓存的源时间或旧派生轨道。

- 时间格式为 SRT 标准 `HH:MM:SS,mmm`，序号连续、段落顺序正确、文本与工程字幕一致；保存对话框可正常取消／保存（本轮通过 AX 设置文件名并保存）。
- 证据的 AX 摘要显示字幕面板按钮与保存面板字段可被辅助技术访问。
