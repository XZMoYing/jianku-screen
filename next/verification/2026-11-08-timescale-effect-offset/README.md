# timescale≠1 时效果轨时间线位置与成片偏移（alpha.104，U22/U23 线索）

## 观察

- 基线 timescale=1：缩放段 2.476–4.578 手柄 x605/992，按 188.5px/s 推得 2.499–4.550s ≈ 配置值。
- timescale=1.5（缩放夹具）：
  - 配置 zoom 2.4757–4.5782；手柄 x840/1427 → 按 188.5px/s 推得 3.745–6.86s ≈ **配置×1.5**。
  - 视频 0–8 段与字幕母版时间（1.79/2.09/4.92/6.51/7.37/8）在手柄上仍按 188.5px/s 对应源时间，未 ×1.5。
- 成片：timescale=1.5 导出 5.333s；大幅帧差（缩放进/出过渡）出现在输出 **2.50–2.97s 与 4.60–5.10s**，与配置 2.4757–4.5782（输出时间基）一致，而非 ×1.5 后的 3.71–6.87。
- 3D 轨：timescale=1.5 下拖 +45px，配置 1.263→1.4205（+0.1575s）= 45px/(188.5×1.5)，即拖动按被放大后的时间线映射写回。

## 假设

效果轨（缩放/3D，可能含样式/图片）在时间线布局/命中映射中把时间乘以 timescale，而导出按配置原始时间渲染；导致时间线位置与成片时间系统性偏移，拖动后的效果时间也与预期不符。可能是用户“偶发偏移”线索之一。
