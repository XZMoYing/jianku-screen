# 音频轨原生交互验收（alpha.89）

安装版 0.2.0-alpha.89／2026.89.0。在自有合成工程上，用真实鼠标事件（CGEvent HID）操作时间线「音频 1」轨道，验证普通移动、左右端裁剪、撤销、非时间字段保持、保存重开、重开后再编辑与播放预览。

## 夹具与定位

- 复制自有合成工程为 `音频轨验收.jks`，改写 `recording-meta.pretty_name`。
- 注入 `timeline.audioSegments` 两段（1.0–2.5「音频A」、4.5–6.0「音频B」），`path` 复用工程内 `content/speech.wav`，duration 8s、trimStart 0、volume 0dB、fade 0，便于只测拖动不改音频参数。
- 重开后轨道头「选择轨道：音频 1」（屏幕 y 854，lane 相对中心 y≈851）；AX 可见「音频A／音频B／2s」、两侧 3px 视觉手柄与顶部淡化滑条。

## 结果

| 步骤 | 操作 | 结果 |
| --- | --- | --- |
| 移动 | 音频A 段内 (460,851)→(510,851) + 保存 | 1.000–2.500 → 1.237–2.737；音频B 不变 |
| 撤销移动 | Cmd+Z + 保存 | 回到 1.0–2.5 |
| 右端裁剪 | 右手柄 (596,851)→(626,851) + 保存 | end→2.642，start 不变 |
| 撤销裁剪 | Cmd+Z + 保存 | 回到 1.0–2.5 |
| 左端裁剪 | 左手柄 (324,851)→(354,851) + 保存 | start→1.142，end 不变 |
| 撤销裁剪 | Cmd+Z + 保存 | 回到 1.0–2.5 |
| 非时间字段 | 上述操作后对比全部非 start/end 字段 | 完全保持（path／name／enabled／trimStart／volumeDb／fadeIn／fadeOut／duration） |
| 保存重开 | 移动到 1.237–2.737 保存后关闭、重开 | 数值保持；AX 重新出现「音频A／音频B」 |
| 重开后再编辑 | 重开后拖动音频A +50 px + 保存 | 1.473–2.973（+0.236 s），音频B 不变 |
| 播放预览 | 空格播放约 2.3 秒 | 时间码 2.00→3.24→4.36，暂停 5.09；音频A／音频B 标签全程在轨 |

## 未覆盖

- 只操作合成夹具，未使用用户真实音频。

## 证据文件

- `au-step-*.json`：每步之后的 `audioSegments`。
- `au-field-preservation.json`：非时间字段一致性对比。
- `au-playback.json`：播放时间码与标签采样。
- `au-ax-evidence.json`：重开后音频轨 AX 节点（含淡化滑条）。
- `au-fixture-segments.json`：注入的音频段夹具。
- `ui-drive.swift`、`editor-dump.swift`：真实输入与只读 AX 工具源码。
