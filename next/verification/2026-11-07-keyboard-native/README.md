# 按键轨道原生交互验收（alpha.89）

安装版 0.2.0-alpha.89／2026.89.0。在自有合成工程上，用真实鼠标事件（CGEvent HID）操作时间线按键轨，验证「普通移动、左右两端裁剪、撤销、保存重开、重开后再编辑、播放预览」。

## 夹具与定位

- 复制自有合成工程为 `按键拖动验收.jks`，改写 `recording-meta.pretty_name`。
- 先在 `content/keyboard.json` 写入合法 legacy 按键事件，界面仍显示「没有按键记录」：`load_project_keyboard_events` 只对 MultipleSegments 工程读取按键文件，单段工程不加载。这是本轮观察到的限制，不判为缺陷，记录于此；后续真实逐键数据仍需用真实采集或合适的合成工程。
- 改用工程配置注入：在 `timeline.keyboardSegments` 写入三条 `kb-edit-fixture-*` 段（start 1.0／3.0／5.2，各带一个 key 与 displayText A／B／C），重开工程后按键轨正常渲染，AX 可见 A／B／C 与段手柄。
- 轨道头「选择轨道：按键」在屏幕 y 804、高 44，lane 中心取窗口相对 y≈801；每步操作前确认应用前台，操作后读取保存的 `project-config.json` 的 `timeline.keyboardSegments`。

## 结果

| 步骤 | 操作 | 结果 |
| --- | --- | --- |
| 移动 | A 段内 (375,801)→(425,801) + 保存 | A 1.000→1.263、end 1.600→1.863；B（3.0–3.7）、C（5.2–6.1）不变 |
| 撤销移动 | Cmd+Z + 保存 | A 回到 1.0–1.6 |
| 左端裁剪 | A 左缘 (326,801)→(356,801) + 保存 | start 1.0→1.158，end 不变 |
| 撤销裁剪 | Cmd+Z + 保存 | 回到 1.0–1.6 |
| 右端裁剪 | A 右缘 (424,801)→(454,801) + 保存 | end 1.6→1.758，start 不变 |
| 撤销裁剪 | Cmd+Z + 保存 | 回到 1.0–1.6 |
| 保存重开 | 移动 A（1.263–1.863）后关闭编辑器、重新打开 | 配置仍为 1.263–1.863；AX 重新出现 A／B／C |
| 重开后再编辑 | A 段内再拖 50 px + 保存 | 1.526–2.126（再次 +0.263 s），B／C 不动 |
| 播放预览 | 空格播放 1.3 s + 1.0 s | 时间码 1.25→2.50→4.03，暂停后 4.35；A／B／C 标签始终在轨 |

- 单次拖动只改被拖段，相邻段不受影响；撤销每次都恢复到精确原值；重开后再拖动差值与此前一致，未见使用旧坐标或错位。
- 未操作真实按键采集数据，A／B／C 为合成 mini 段（每段一个 key、timeOffset 0）；内部逐键 timeOffset 的裁剪重基仍归 U22c2b5t。
