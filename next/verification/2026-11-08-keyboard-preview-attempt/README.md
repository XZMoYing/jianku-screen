# 键盘预览逐键采样尝试（alpha.108，U22c2b5p 剩余项）

## 方法与观察

- 打开按键逐键验收夹具，单窗口取帧 6s/159 帧（~26fps），期间空格播放 3.5s。
- 用 ffprobe 帧时间计算预览区域连续帧差，与期望键切换时间（a/段1 起 2.14、b 2.64、c 3.34、段1 末 3.66、段2 起 4.83、段2 末 5.43，均已按播放动作时间换算）对照。
- 实测峰值集中在 1.39/1.47 与 3.04–3.45，与 2.14/2.64 偏差较大，无法可靠对齐。

## 结论

本次预览逐键采样**未能可靠对齐**期望时间（可能因播放启动相对动作时间延迟、窗口取帧帧率/时间戳不均匀、视频内容自身变化）。**不能据此判定预览逐键通过或失败**；导出逐键已于 2026-11-08-keyboard-export-keys 验证。
