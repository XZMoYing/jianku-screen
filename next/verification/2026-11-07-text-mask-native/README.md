# 文字轨与遮罩轨原生交互验收（alpha.89）

安装版 0.2.0-alpha.89／2026.89.0。在自有合成工程上，用真实鼠标事件（CGEvent HID）操作时间线「文本 1」「遮罩 1」两条轨道，验证普通移动、两端裁剪、最小时长限制、撤销、非时间字段保持、保存重开与播放预览。

## 夹具与定位

- 复制自有合成工程为 `文字遮罩验收.jks`（及用于干净复验的 `文字遮罩验收2.jks`），改写 `recording-meta.pretty_name`。
- 注入 `timeline.textSegments`（1.0–2.0「文字甲」、4.5–5.5「文字乙」）与 `timeline.maskSegments`（2.5–3.5 隐私、6.0–7.0 重点）。
- 重开后轨道头「选择轨道：文本 1」（y 854，lane 相对中心 y≈851）与「选择轨道：遮罩 1」（y 904，lane 中心 y≈901）；边缘手柄视觉宽 3px、命中容器宽 20px。

### 起点裁剪与最小时长（干净复验）

- 源码常量：文字轨／遮罩轨 `MIN_SEGMENT_SECS = 1`、`MIN_SEGMENT_PIXELS = 80`，`minDuration = max(1s, secsPerPixel*80)`。
- 首轮夹具段落正好 1.0 秒，从起点向右拖（缩短）时被最小时长钳制、无变化；这不是起点手柄失效。
- 先把 end 拉长、再缩起点，均正常：`文字遮罩验收2` 上文字 end 2.0→2.378 后 start 1.0→1.142；遮罩 end 3.5→3.878 后 start 2.5→2.642；两次撤销均精确回到原值（`tm2-step-*.json`）。
- 向左侧起拖可把起点提前：文字 1.0→0.858、遮罩 2.5→2.358（首轮夹具，未持久化为单独步骤文件，数值见本节与运行记录）。

- `ui-drive.swift`、`editor-dump.swift`：真实输入与只读 AX 工具源码。
