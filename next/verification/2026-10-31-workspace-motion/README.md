# 首页模式与录制来源切换：源码验证

用户恢复后已验证包含最后补丁的最终源码：45 项界面/面板加 11 项异步请求检查、类型检查、完整前端构建及作用域格式全部通过。`source-validation.json` 记录最终文件及日志哈希，暂停前日志只保留为历史。

本单元 U20b6a 在基线 7d5ddb5 上完成，安装中的应用仍是 alpha.49 / 2026.49.0；没有重启、激活、抬起或替换用户正在运行的应用。U20b6b 的实际包、WebView 观感及设备连接验收继续待办。

## 改动

- 录屏/演示与电脑/移动来源分别用同一 MotionSwitch 先退出再进入；每层只有一个 MotionPanel 参与布局，保留演示及移动设备组件实例。沿用共享界面弹簧参数，没有改动屏幕缩放、光标、3D 运镜、动态模糊或导出画面曲线。
- 视频/截图控制移到来源动画之外，避免新 transform 改变其绝对定位参照；标题控制仍用共享 Presence 进入/退出。悬停说明在所属页面失活时取消，隐藏后不能继续打开设置或切换捕获方式。
- 共享交互状态沿父子面板传递，退出及隐藏的选择器关闭 Portal 菜单且不写值，取消时不把焦点送回隐藏按钮。原有业务禁用保留；从面板内发起切换时把焦点交回相应导航，外部焦点不被抢走。
- 原生浮层关闭属于异步步骤；新模式请求使旧请求失效。重新点击当前模式也能取消未完成的切换，旧结果/旧错误不覆盖最后选择；等待期间开始录制、进入忙碌状态或开始演示会阻止不再适用的切换。页面销毁后不再提交或显示过期错误。
- 模式请求返回是否接受，录制库/截图库只在请求仍有效时继续打开；切换被后来点击取消时，不再误开库菜单。
