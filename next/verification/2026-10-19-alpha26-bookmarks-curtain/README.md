# alpha.26：书签、演示幕布与移动录制计时

日期：2026-10-19。开发前的远端回滚点为 `backup-next-alpha25-20261019`，提交 `d0cf481918b7603c06ab5d003735927c098e765f`。

## 变更

- 电脑独立 Studio 录制可添加书签。源坐标使用捕获管线的单调媒体基准，录制静止画面时仍前进，暂停后固定在上一源片段的末尾；恢复录制使用下一个源片段。
- 书签独立保存在工程的 `recording-bookmarks.json`，原子替换并校验，不改写原始音视频。编辑器按最终原始素材的完整范围解析片尾书签，保留原观察时间供核对；解析结果只用于当前显示，不改写捕获时间。解析不使用剪辑后的范围，避免将已剪掉的书签错误地移到新片尾。编辑器提供命名、删除及按当前剪辑跳转，适配剪除、重排、重复使用、变速、转场与全屏文字停留。
- 演示幕布即时遮盖输出窗口，并将后台输出替换为不透明的中性色画面。GPU 回读完成后再次检查状态，遮盖期间不发布旧画面。遮盖时继续检查来源与输出屏幕连接，新会话恢复正常输出。
- 新操作可在设置中配置独立快捷键，默认不占用系统按键。冲突、注册与保存失败均报错；未成功的绑定不会覆盖原设置。
- 移动录制计时由录制事件控制，状态查询不修改时钟，结束计时排除保存过程。`mobile-timing.json` 保存观察时长、媒体时长和时钟来源；明显不一致时提示用户检查结尾。

## 验证方法

`fixture.swift` 创建只含合成颜色与文字的静止窗口；`review.js` 通过现有 debug 检查入口操作真实按钮及原生命令。录制请求选择该窗口。最终逐段解码检查发现当前 macOS 窗口录制实际使用显示器区域裁剪：首段包含遮挡该区域的浏览器，恢复后为合成窗口。因此此项仅证明指定区域录制与书签时序闭环，不证明窗口内容隔离，也不能声称本地录制只包含合成画面。原始录像及完整窗口截图均未提交。演示接收的桌面帧仅在内存采样检查是否遮盖，不保存帧、桌面截图或私人媒体。

检查脚本使用临时的 `jianku-alpha26-review` 本地状态，测试结束清除。快捷键冲突测试使用新功能默认未绑定的按键并在结束后撤销；演示设置结束后还原。

## 已知限制

- V2-Mobile-11 仍未解决。本机目前没有连接安卓设备，新增时长核对不能代替实机录制修复。底层 scrcpy 的录像结尾对最后一个视频包固定设置 100,000 微秒，设备端默认请求重复静止帧；仍需确认特殊设备实际编码输出是否遵守该设置。参考仓库已存的 `research/evidence/2026-10-14-scrcpy-options/app/src/recorder.c` 和 `SurfaceEncoder.java`，不凭墙钟统一拉伸原始媒体。
- 书签仅支持独立电脑 Studio 录制；即时、移动设备、为已有工程追加录制片段以及独立书签轨道不在当前范围。
- iPad、实际副屏/会议共享和 Windows 实机按既有交接范围继续等待，短时共享窗口检查不等于这些场景全部通过。
- 正式开发者签名、低概率长工程播放问题与既有未实现项继续以唯一交接清单为准。

## 本机已通过

- 原生：书签源映射与保存 3 项，移动录制 7 项，幕布/比例 2 项，快捷键冲突 1 项，绑定导出 1 项；前端播放/标题/本地化回归 44 项。桌面完整 TypeScript 检查、相关 Rust 检查与格式检查通过。
- 静止合成窗口：录制→添加书签→暂停两秒→添加两次书签→恢复→录制条按钮添加→停止并自动打开编辑器。暂停书签两次均为 `2.095378542` 秒；恢复后的书签属于源片段 1。实际工程时长 `4.4197` 秒，暂停时间不进入录制。
- 编辑器：四个书签都能投射到实际时间线，命名、跳转、删除通过；关闭并重新打开工程后，名称和删除结果保留，剩 3 个书签。独立重开工程的跳转位置连续三次相隔一秒均为 `0:02.04`。截图只保留书签面板区域。
- 演示：真实按钮遮盖/恢复、遮盖状态保持、快速切换 10 次、遮盖中改变输出尺寸、停止并重启通过。窗口遮盖元素与后台不透明帧同时核对，不保存桌面画面。
- 快捷键设置页：通过真实页面录入、保存、制造冲突、确认错误回退、清除绑定；测试结束未留下临时按键。

详细数值见 `observations.json`。最初的验证发现录制估计边界与封装后素材边界相差数帧；因此解析改用编辑器已加载的最终素材时长，不能改回用临时估计值或按剪辑后的边界钳制。原始捕获时间保留在书签文件中。

普通书签跳转在最终打包前补充了原生播放头同步；准备阶段拒绝跳转时保留列表并提示重试。它们通过类型检查，源映射和实际窗口流程如上，不宣称已覆盖全部交接/准备时序。停止/重建演示时出现 GPU 回读取消日志，未见活跃会话错误；此次没有将日志全部无错误作为验收结论。
