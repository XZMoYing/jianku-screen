# 3D 镜头相邻/间隔衔接导出分析（alpha.108，U27 部分）

夹具：3D拖动验收.jks（原段 1.26–3.26 / 5.0–7.0，joinDuration 0.75）。改造为相邻段 1–3（zoom 2/pan −0.2）与 3–5（zoom 1.5/pan 0.2），再改造为间隔段 1–3 / 5–7 对照，用安装包 cap-cli 导出 640×360/30fps 后逐帧分析。

## 结果

- 相邻段导出：240 帧、无黑帧；段起点帧差 82.97；**join（2.8–3.2s）最大 16.29、均值 12.23**（约 0.2s 混合过渡）；第二段结束（5.0s）帧差 79.43。
- 间隔段导出：240 帧、无黑帧；起止边界帧差 82.97/82.99/79.45/79.43，呈明显突跳（效果出现/消失），符合“无段即无效果”。
- 结论：3D 相邻段 join 有混合过渡、间隔段边界突跳，导出连续无黑帧/丢帧；U27 的“相邻/间隔/导出连续性”部分验证。
- 未覆盖：位置/速度曲线逐帧定量、运动模糊历史统一、显式切镜组合、真实素材与用户舒适度确认。
