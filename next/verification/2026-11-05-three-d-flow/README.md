# 自动3D镜头的衔接问题

直接调用当前three-d.ts的autoCamera3DScene(3)、applySceneToRange(...0,12)、getStartPose/getEndPose，得到4秒和8秒两处相邻边界，入/出过渡全为0；第一处tiltY跳44.04°、rotateX跳-40°、FOV跳15°，第二处tiltX跳-34.19°等。它们是创作数据的不连续，不是渲染器帧率抖动；这是端点探针，不是成片验证。

当前每段各自采用已共享的弹簧轨迹，但自动场景仍刻意硬切，曝光历史也只给数学上相同的拆分轨迹跨切点延续。用户现在要求观看连贯，因此下一实现应让默认相邻镜头接成连续过渡，保留明确的直接切镜选项；不能只改一个普通ease或关闭模糊。

实现方向：相邻有效镜头在边界两侧留出受片段长度限制的衔接区；在同一原生采样函数内取两侧姿态，使用现有共享缩放弹簧节奏插值，保证衔接区两端位置／速度接回原轨迹，旋转取合理短路径。运动模糊采样读取同一衔接后的轨迹，跨有效衔接保留曝光历史，直接切镜／空隙／重叠不误混。景深模式不同需避免在强模糊时突然换算法；后续以实际画面打磨，不能只通过端点等式。UI用简单“平滑衔接／直接切换”和时长，复杂曲线仍收二级。

本单元只有定位和产品处理方向，源码未改，仍待实现和真实预览／成片。61冻结构建进行中，不改该候选输入。优先完成61默认最大化细节，再接本单元；光标拖动的静态参考事件分类仍继续核查。
