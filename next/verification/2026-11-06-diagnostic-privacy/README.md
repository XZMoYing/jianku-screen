# 本地诊断报告的标识与子进程输出

既有报告只在部分字段替换主目录。显示器、摄像头、麦克风和音频输出可以携带设备名称或系统标识。设置和存储信息仍可能保留外置盘、共享盘的路径。同步测试的错误和 stderr 尾部还可能出现在报告或日志中。

Tauri 本地报告现用报告内的设备序号，保留分辨率、帧率、采样率、声道和时钟数据。移除最近录制的设备标识与原始错误，保留状态和错误存在性。记录目录设置只留下是否自定义与历史目录数量，存储信息继续保留容量。同步子进程 stderr 不进入应用报告或日志，stdout 按现有协议提取固定阶段、判定、数值测量和阈值，摘要由测量值重建。原 CLI 独立运行的详细输出保持。

两项合成同步报告测试通过。覆盖非主目录与 Windows 路径、未知字符串键、混入测量的字符串、未知判定和保留测量。桌面及测试代码的 macOS release check、Rust 格式和差异检查通过。未开启真实录制、未读取旧报告或日志、未上传。包含此改动的安装包和实际诊断窗口待验。
