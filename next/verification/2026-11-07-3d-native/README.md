# 3D 镜头轨道原生交互验收（alpha.89）

安装版 0.2.0-alpha.89／2026.89.0。在自有合成工程上，用真实鼠标事件（CGEvent HID）操作时间线 3D 轨，验证「普通移动、左右两端裁剪、撤销、取消（Esc）、姿态字段保持、保存重开、重开后再编辑、播放预览」。

## 夹具与定位

- 复制自有合成工程为 `3D拖动验收.jks`，改写 `recording-meta.pretty_name`。
- 在 `timeline.camera3dSegments` 注入两个默认姿态的 2 秒镜头（1.0–3.0、5.0–7.0），重开工程后轨道头出现「选择轨道：3D」（屏幕 y 904、高 44），镜头显示「固定镜头／2.0 秒」，片段组与 4px 边缘手柄可读。
- 轨道 lane 中心取窗口相对 y≈901；每步操作前确认应用前台，操作后读取保存的 `project-config.json` 的 `timeline.camera3dSegments`。

## 观察与测试更正

- 右缘手柄只有 4px 命中区；本轮第一次「右端裁剪」在 x689（距手柄 2px 的段内）按下，被组件识别为整段移动（start 与 end 同时 +0.158 s），已废弃该步并用 x692 重测；记录以避免把测试误差当缺陷。窄手柄本身是否符合操作预期，留待用户实际体验确认。
- Esc 在 3D 移动中把片段还原到原位置且不新增撤销；这与缩放轨「已创建后取消保留最后有效范围」不同，属于各组件既有语义，本轮不作对错判断。
