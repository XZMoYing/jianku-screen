# 变速工程字幕投影观察与拖动尝试（alpha.104，U25b）

在 alpha.104 上，用「字幕轨验收」夹具注入 timeline.segments[0].timescale=1.5（原字幕存在 1.79–2.09 空隙与 4.92 邻接），观察字幕时间线投影并尝试拖动/裁剪验证跨 timescale 的母版回写。

## 观察

- 打开后时间线 captionSegments 为母版按 timescale 的派生投影：
  - 母版：(0,1.79)、(2.09,4.92)、(4.92,6.51)、(7.37,8)
  - 时间线：(0,1.193)、(1.393,3.28)、(3.28,4.34)、(4.913,5.176)，即母版时间 /1.5；空隙与邻接关系保持。
- 拖动工具本轮不稳定：多数拖动未生效；在前台应用确认为 com.jianku.screen.next 时，一次视频右缘裁剪生效（8.0→7.7635，约 -40px），证明事件工具本身可用。
- 字幕拖动/裁剪多次尝试未改变母版或时间线，未取得可判定结果。

## 结论

确认变速工程中字幕时间线是母版按 timescale 的派生投影（比例正确、空隙保持）；但**未能验证 timescale≠1 下字幕拖动/裁剪的母版回写与重开持久化**。不据此关闭 U25b。

## 未覆盖

- timescale≠1 下字幕拖动/裁剪回写母版与重开持久化；SRT/VTT 在变速投影下的时间；转场/变速/空隙真实工程组合；拖动自动化稳定性。
