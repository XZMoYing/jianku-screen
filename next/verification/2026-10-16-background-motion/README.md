# 背景、切换动效与首页预览验证（alpha.17）

环境：Apple M1、macOS 14.7.4、Metal、已签名的本地 debug 试用包；首页 1120×800，预览仍为 960×600 RGBA。实际应用内运行，未启动开发服务器。

## 已验证

- 首页和视频编辑器各遍历桌面、壁纸、网格、图片、颜色、渐变、动态七类；只浏览分类不改变已应用背景。编辑器读取实际 `project-config.json` 比较背景配置，首页读取原生保存配置。
- 实际选择网格会更新 GPU 预览与保存配置。两处均验证选择其他素材后点击桌面预览能重新应用桌面背景；编辑器重复往返一次。
- 首页、视频编辑器与截图编辑器直接复用 `BackgroundSettings`，包括图片/视频选择、颜色、渐变细调、动态渐变库及本机壁纸。静态截图仍在静态帧渲染，不因此成为动态媒体。
- 编辑器依次切换光标、声音、画面、按键、画面，真实内容与选择相符。截图见本目录 `home.png`、`editor.png`；二者使用自制工作台图表。
- 首页播放测量 16 秒，排除前 3 秒暖机：712 个显示确认、54.92 fps，帧间隔中位数 18 ms、P95 21 ms、最大 45 ms，没有超过 50 ms 的间隔。`document.visibilityState` 为 `visible`。
- 旧串行链路的对照使用相同配置、相同分辨率，执行原生即时渲染、Base64 编解码、行拷贝及原有额外 33.3 ms 等待；暖机后的平均间隔 144.73 ms，对应帧率上限 6.91 fps。该数值不包括旧画布上传，不应描述为运行旧安装包的完整帧率测试。
- 额外以相同配置和 0.7 秒的同一采样时刻，逐行提取旧 Base64 响应与新二进制 watch 帧的 960×600 RGBA；2,304,000 个像素字节的 SHA-256 一致。该项覆盖固定的自制/渐变场景，不替代 HDR/所有动态背景的检查。
- 新链路继续使用同一 GPU 合成与 RGBA 数据、相同分辨率、相同模糊采样及光标/阴影设置。优化来自持续复用渲染会话、固定时钟、二进制 watch 通道及独立 OffscreenCanvas 显示线程。没有以降低效果、采样或预览清晰度换取结果。

## 检查

桌面 TypeScript、改动文件 Biome、13 项前端相关测试、Rust 编译检查通过。新增原生系统素材分类 1 项测试通过；应用深层严格签名检查通过。CSS 的减少动态效果规则保留已有四项 `!important` 提示。

## 实际边界

本次连续播放数据来自上述自制示例和渐变背景，不代表所有高帧率 4K 系统视频壁纸、所有机器及所有工程。读取本机壁纸和 HEIC 转换有首次准备成本；缩略图并发有界，分类浏览不会应用候选。本机未下载的视频不会联网获取；程序化壁纸仍按已有静态回退处理。

动效按归档 DogSC 源码中的退场、分组入场、方向子页面和弹簧参数实现；本次没有证明 SwiftUI 与 WebView 每个合成像素完全相同。全部高级业务页面、键盘/触控板、快速反向、减少动态效果及深色主观观感仍需继续验收。Inset 与原有安卓静止尾段时长 P0 未在本阶段解决。

代码依据及参数见 `research/evidence/2026-10-16-background-motion/manifest.json`；工程源目录位于 `next/cap/`。
