# 主窗口置顶/最小化/全屏/关闭重开原生验收（alpha.96，U21b2 窗口分项）

安装版 0.2.0-alpha.96 / 2026.96.0。用 AX 控件操作 + CGWindowList 层号读取，核对首页主窗口的普通窗口行为与置顶偏好。

## 结果

| 用例 | 结果 |
| --- | --- |
| 默认状态 | 主窗口 1120×800 @ (250,98)、AXStandardWindow；置顶复选框值 0、CGWindow layer 0（普通层） |
| 开启置顶 | 控件文案变「取消主窗口置顶」、值 1；CGWindow layer 0→5（浮层） |
| 置顶跨重启 | 正常退出并重开应用：值 1、layer 5 保持 |
| 关闭置顶 | 文案变「主窗口置顶」、值 0；layer 5→0 |
| 最小化/恢复 | AXMinimized true、AXMain false；恢复后 false，尺寸/位置 1120×800 @ (250,98) 复原 |
| 全屏进入/退出 | AXFullScreen true、尺寸 1680×1050 @ (0,0)；退出后 false、尺寸/位置恢复 1120×800 @ (250,98) |
| 关闭主窗口（红钮） | 窗口关闭、应用进程仍在；`open -a` 重开主窗口于 1120×800 @ (250,98) |
| 置顶跨关闭重开 | 开启置顶→关闭窗口→重开：值 1、layer 5 保持；随后关闭置顶恢复 layer 0 |

- 结论：主窗口为普通窗口（默认非置顶），置顶偏好可切换并在重启/关闭重开后保持；最小化、全屏往返尺寸位置恢复正确；关闭红钮只关窗口不退出应用，可重新打开。
- 测试结束已关闭置顶、应用正常退出，未使用用户真实工程。
