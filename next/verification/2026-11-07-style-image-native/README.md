# 样式轨与图片轨原生交互验收（alpha.89）

安装版 0.2.0-alpha.89／2026.89.0。在自有合成工程上，用真实鼠标事件（CGEvent HID）操作时间线「样式 1」「图片 1」两条轨道，验证普通移动、左右端裁剪、撤销、非时间字段保持、保存重开、重开后再编辑与播放预览。

## 夹具与定位

- 复制自有合成工程为 `样式图片验收.jks`，改写 `recording-meta.pretty_name`，并在 `content/image.png` 放入项目 logo 作为图片素材。
- 注入 `timeline.styleSegments` 两段（1.0–2.5「样式A」、4.0–5.5「样式B」，overrides 为空）与 `timeline.imageSegments` 两段（2.0–3.0「图片A」、5.0–6.0「图片B」，center 0.5/0.5、size 0.3/0.3、不透明、不翻转、锁定比例）。
- 重开后轨道头为「选择轨道：样式 1」（屏幕 y 854）与「选择轨道：图片 1」（y 904），lane 相对窗口中心分别 y≈851／901；边缘手柄宽 4px。

## 结果

| 步骤 | 操作 | 结果 |
| --- | --- | --- |
| 样式移动 | 样式A 段内 (460,851)→(510,851) + 保存 | 1.000–2.500 → 1.263–2.763；样式B 与两条图片不变 |
| 样式撤销 | Cmd+Z + 保存 | 回到 1.0–2.5 |
| 样式左裁剪 | 左手柄 (326,851)→(356,851) + 保存 | start→1.158，end 不变 |
| 样式右裁剪 | 右手柄 (598,851)→(628,851) + 保存 | end→2.658，start 不变 |
| 图片移动 | 图片A 段内 (602,901)→(652,901) + 保存 | 2.000–3.000 → 2.263–3.263；样式轨道与图片B 不变 |
| 图片左裁剪 | 左手柄 (516,901)→(546,901) + 保存 | start→2.158 |
| 图片右裁剪 | 右手柄 (693,901)→(723,901) + 保存 | end→3.158 |
| 非时间字段 | 上述操作后对比全部非 start/end 字段 | 样式与图片均完全保持（overrides／name／track／enabled、path／center／size／opacity／rotation／rounding／flip／lockAspect） |
| 保存重开 | 样式A 1.263–2.763、图片A 2.263–3.263 保存后关闭、重开 | 数值保持；AX 重新出现「样式A／样式B／图片A／图片B」与 4 个片段组 |
