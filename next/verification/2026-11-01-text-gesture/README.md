## 原问题

真实TextOverlay配实际历史的新增11项初始回归中，9种中断均未结束历史暂停，普通点选还产生额外撤销步骤，10失败/1通过。旧实现独立root监听window.mousemove/mouseup，组件移除、时间离开、失焦/删除等并不结束拖动，帧回调和节流写入继续持有旧数组索引。before.log.gz保留原失败。

沿退出流程另确认：编辑空文字后，原片段被替换时，旧组件清理按旧index删除了新片段。inline-before.log.gz保存真实组件的错误删除请求；修复后只按当前片段身份删除自己的空文字，旧目标已移除时不删替换段。

## 修正

文字移动和缩放接入已验证的共用鼠标监听控制器，生命周期归当前文字段所有。中断时移除旧监听、取消待执行rAF及节流提交、结束历史一次并清理局部覆盖/吸附线。目标启用状态、当前时间范围、片段身份、画布尺寸或timeline上下文改变会结束旧手势。已销毁的控制器不能重新注册事件。Esc/失焦保留最后已提交有效值，不提交失效目标的队列；正常松手仍提交最终坐标。

保留原逐帧局部反馈和1000/FPS节流写入，移动/缩放/钳位/吸附计算与视觉参数不改。只在跨过原2像素阈值时暂停历史，纯点选不新增撤销。撤销/重做快捷键先结束活动拖动再按原冒泡路径执行；时间线文字/遮罩/音频同用的控制器回归也覆盖此变化。缩放后的测量帧有owner清理和目标校验，后续新手势会取消旧测量。
