2026-10-31用户反馈：首页始终置顶，应默认不置顶并让用户选择，支持正常关闭、最小化与全屏；录制中的浮窗保持。此目录先记录源码检查，当前安装仍alpha.48，下一包alpha.49/2026.49.0尚待完整构建和实际验收。

## 根因与源码改动

旧48实际窗口读取得到AXDialog、层级5，且没有原生关闭/最小化/缩放按钮，见[旧版窗口记录](alpha48-window.json)。Native Main构建禁用了最小化/最大化，并转换成NSPanel、FullScreenAuxiliary；前端权限请求完成又硬编码setAlwaysOnTop(true)。仅改启动默认值不能覆盖这些路径。

Main改成普通窗口，启用原生标题栏的三按钮、最小化/最大化，读取新偏好mainWindowAlwaysOnTop（缺失与新默认均false）；全屏时跳过自定义可见区域裁剪。Mac首页不再叠加自绘三按钮，其他窗体路径保留；顶栏Pin与设置按钮使用共享EditorButton。

Pin开关保存偏好，权限窗口降级与还原使用同一串行队列；Main返回权限设置时读取最新用户选择，其他浮窗还原原来的置顶状态。保存失败回滚实际窗口状态和偏好，并保留回滚错误；窗口权限失败不写偏好，防止改变其他窗口。没有更改录制控制条、摄像头和来源选择原生构建分支，也不改变已认可的画面动效/渲染、工程媒体或网络。
