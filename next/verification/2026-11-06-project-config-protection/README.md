# 工程配置读取保护

alpha.83 的自有夹具含无法解析的已有配置。编辑器通过 `RecordingMeta::project_config` 回退到默认值，继续创建时间线并可保存到原路径。该风险也存在于桌面截图编辑、追加导入目标和自动化套用预设。常规成片导出和快速导出预览已有严格读取，光标单独导出和独立预览此前也通过默认值回退。

已共享缺失配置的默认行为。只有配置路径确实不存在时才使用默认值。解析、读取、权限错误和悬空链接继续向上返回。录制编辑器在创建或保存默认时间线前停止，显示保留原配置的提示，并提供重新加载和工程位置入口。追加导入的来源与目标读取失败时不进入素材写入。截图编辑、自动化预设、独立导出预览、光标单独导出和录制恢复也接入该检查。已有合法配置及旧字幕侧车仍可读取。

macOS 原生验证通过。录制编辑器创建入口收到结构无效的配置后直接返回错误，原始字节完全一致。工程模型的缺失、语法错误、结构错误和悬空链接检查通过，9 项元数据测试包含旧字幕兼容。桌面、CLI、编辑器、导出、录制、工程模型及性能工具的 release 编译检查通过，覆盖各自示例。检查时补上桌面传输示例两处缺失的可选片段 ID。桌面类型、Biome、Rust 格式及 18 项前端保存和语言测试通过。

范围为读入既有配置时的保护。已打开工程的外部并发修改、独立 GPUI 应用、Windows/Linux 与最终安装包交互待后续验证。当前安装仍为 alpha.83。下一候选包用有效、损坏和缺失配置三份独立工程验收，并比对失败分支的原始字节。
