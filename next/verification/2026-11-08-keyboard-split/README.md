# 按键段分割/失焦中断/预览实包验证（alpha.97，U22c2b5p 部分）

安装版 0.2.0-alpha.97 / 2026.97.0。在自有工程注入按键段 `kb-edit-verify` 1.0–3.0（displayText `abcd`，keys a@0／b@500／c@1200／d@1800），验证分割、失焦中断与预览；过滤项与选择/删除本轮未验证成功，不声称完成。

## 结果

| 用例 | 操作 | 结果 |
| --- | --- | --- |
| 分割 | 开启「分割工具」，播放头约 1.997 处点击键盘段 | 分为 1.000–1.997「ab」（a@0／b@500）与 1.997–3.000「cd」（c@202.6／d@802.6，绝对时间≈2.2/2.8 保持）；displayText 同步分区；分割工具可关闭 |
| 失焦中断 | 按住键盘段拖动 50 px 后切到 Finder，再松开鼠标 | 配置保持分割后值（1.000–1.997／1.997–3.000），无错误写入、无崩溃 |
| 预览播放 | 空格播放约 1.4 s | 时间码推进到 0:03.06，播放/暂停可用 |
| 单选删除 | 单击 A 段后 ⌫ | A（1.0–3.0）被删除、B（4.0–4.6）保留；一次撤销恢复两段 |
| Cmd 多选删除 | 单击 A 后 Cmd+单击 B，再 ⌫ | 两段同时删除；一次撤销恢复 A 与 B 原始范围 |
| 菜单「选中此轨道的全部片段」+ ⌫（首次尝试） | 未删除；后续用单击/修饰键点击确认选择删除路径可用 | 菜单项点击后焦点/菜单态导致 ⌫ 未生效，改用直接选择验证通过 |

- 测试后工程恢复为 1.000–3.000「abcd」并正常退出；未使用用户真实工程。
