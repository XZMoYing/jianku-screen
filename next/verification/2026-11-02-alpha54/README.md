## 导出与异步编辑

五份工程均用安装包内导出器以1280×720、30帧、最高质量导出H264／AAC。成片时长4／4／16／10／15秒，总49秒；ffprobe实际全段解码120／120／480／300／450帧，共1470视频帧，无导出ERROR或解码错误。见`export-results.json`和工具源码。测试尺寸未改变产品默认质量；耗时仅记录观察值，不构成性能或严格颜色验收。

另建独立异步编辑案例，先确认原生预览已显示，再临时写入含50万条合成移动的事件文件（约39.5MB），点击数据保持。原生工具先读回生成按钮禁用、再等150毫秒确认仍在忙碌，随后点击背景色按钮。实际出现过期结果提示，新背景从[239,235,225]变为[214,202,177]并保存，镜头始终为空，后续检查稳定。原小事件文件已按原字节恢复并核对SHA，临时大文件未保留。见`async-result.json`、`async-acceptance.py`。

这个检查确认**实际生成忙碌期间的编辑保护**；没有区分等待保存或原生计算的具体阶段，也没有单独强制构造旧预览watch乱序覆盖。最终命令直接读取flush后的保存文件，源码边界已检查，这个更具体的运行时交错仍作为U23b2q待验。不能把一次颜色编辑外推为全部异步情形。
