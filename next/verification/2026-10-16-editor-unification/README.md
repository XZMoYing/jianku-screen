# 0.2.0-alpha.16 验证记录

本轮范围：系统主题切换、首页与编辑器共用画面控件和渲染器、横向分栏、Material 滑块、当前壁纸及动态背景、中英文与本地账号提示。

## 已执行

- 桌面 TypeScript 检查；改动文件 Biome 检查。CSS 中保留原有减少动态效果的四处 `!important` 警告，没有新增忽略规则。
- 前端 15 项：语言解析与字典、编辑器布局约束、动态配色、光标样式。
- 原生 19 项：视频背景解码、回退寻帧与循环 2 项；壁纸 display/provider 选择 2 项；窗口排除 15 项。
- 动态视频使用自制 `testsrc2` 测试片，不复制或分发系统壁纸；本机系统壁纸只验证识别和渲染，不保存它的像素到仓库。

打包应用的运行结果、截图及导出检查见同目录证据；只使用合成工程。

应用内验证已覆盖首页真实 GPU 像素、留白保存与演示同步、1120×800 / 660×530 布局、移动/演示页滚动、快速切换、按住和取消反馈、壁纸取色恢复。设置覆盖深色→跟随系统及快速反向，语言 en→zh-CN 与本地账号提示。编辑器分栏实测 352→424→352 px，光标面板滑块轨道为 8 px。

语言保存回调最初同步刷新托盘，会在 store 尚持锁时再次读取 store。应用内测试复现卡死，采样栈确认 `Store::set → emit_change_event → interface_language::refresh → StoreExt::store`。现将刷新放到阻塞工作线程，回调立即返回；复测语言往返、编辑器操作、导出及正常退出通过，退出用时约 726 ms。

构建必须使用 `CARGO_INCREMENTAL=0 node scripts/jianku.mjs build`（本机构建缓存曾丢失增量临时目录）。该入口同时更新 `cap-cli` / `cap-exporter` 和桌面包。仅直接运行 `tauri build` 会沿用旧的导出组件；本轮发现旧组件把视频背景误作图片并回退白色，不能把它生成的文件视为动态背景导出通过。

## 实现边界

首页是使用真实合成器的“画面示意”，输入内容是自制示例窗口、摄像头占位图和指针事件，不是正在捕获桌面。默认只在参数变化时渲染；点击播放后按单次请求合并调度，隐藏窗口暂停。

现有媒体光标、缩放、点击和模糊求解器保留。控件取值与保存结构共用，不意味着各动画已达到参考软件逐帧一致。

动态桌面支持当前 provider 能对应到本机实际视频文件的系统壁纸；找不到视频时保留当前静态快照。多 Space、第三方程序化壁纸、未下载资源、HDR 及多屏各自壁纸仍需人工验收。工程引用本机系统视频；跨机器请使用工程副本功能并检查资源许可。

旧 `background.inset` 参数没有进入上游渲染链；本轮共用控件标为“敬请期待”并禁用，保留已有工程值，不宣称该功能已实现。

账号登录、升级入口显示本地待开放提示；用户不会从这些入口进入上游账号系统。版权、源码和依赖许可中的 Cap 名称依法保留；不批量改写用户内容、文件名、格式、第三方服务名或协议标识。

默认简体中文，可选 English 或跟随系统；非中文系统回退 English。主要窗口、编辑器、截图、录制、演示及设置的静态文案已接入字典。高级运行时错误、带数据的状态文本和文本溢出仍需逐流程人工覆盖，不把字典数量当作所有路径完成的证明。

P0 `V2-Mobile-11`（特殊安卓设备静止尾段时长）继续未解决；iPad 实机与 Windows 仍按用户要求延后。

## 最终成片及应用包

最终组件一起重建并通过 `codesign --verify --deep --strict`。首次签名因开发钥匙串锁定返回 `errSecInternalComponent`，解锁本机开发钥匙串后重新签名和严格检查通过；不以那次失败的签名作为发布结果。

- `workspace-smoke.json`：首页 GPU 输出 960×600，有实际像素；宽/窄布局无横向溢出，参数保存和演示同步通过。
- `runtime-checks.json`：深色→系统、快速反向、en→zh-CN、账号提示、动态壁纸、左右分隔和共用光标控件通过，没有记录到 JS error / unhandled rejection。系统 MOV 只记录媒体类型及帧哈希，没有保存系统素材。
- `export-probe.json` / `export-validation.json`：最终导出 H.264 960×600、30 fps、6 秒、180 帧，全片解码无错误。1.2 秒自制动态背景在六秒输出中循环；外侧 40 px 背景区域的 RGB 平均绝对差：0→0.8 秒为 22.9653，0→1.2 秒为 1.3622（有损编码后），表明背景有运动且循环返回。
- `export-dynamic.mp4`：该合成导出的视频轨副本，使用 stream copy 保持图像不变，去除音轨；`export-start.png` / `export-moving.png` / `export-loop.png` 为原始导出的三个时间点。
- `quit-check.json`：完成语言切换和导出后正常退出约 726 ms；最后再启动正常试用实例，不带测试环境标记。
- `main-wide.png` / `main-narrow.png` / `editor-layout.png` / `editor-dynamic.png`：全部为自制示例与合成测试媒体。首页画布按实际比例和可用宽高共同约束，已修复底部裁切；不保存真实桌面或会议内容。

本轮成功的成片使用新导出组件；此前白色背景的旧导出不在证据中。机器上没有对 iPad、会议软件、副屏、第三方动态壁纸或全部错误路径做验收。人工剩余范围以交接清单为准。
