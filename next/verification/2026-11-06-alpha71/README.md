# alpha.71 工程名撤销对照

alpha.71 中间版 21a00de 已签名归档和安装。初次 Cmd+Z 测试停留在中文输入法组字阶段。独立 WebKit 探针捕获了组字开始、回车提交和提交后的 historyUndo 事件。

真实应用对照使用分开的自有工程。alpha.70 和 alpha.71 在提交组字后都能用 Cmd+Z 撤销、Shift+Cmd+Z 重做。alpha.70 第一次回车提交时会退出工程名输入，alpha.71 保留焦点。alpha.71 同一工程内也验证了文字撤销与转场历史隔离。alpha.72 移除冗余的自定义撤销栈，仅保留回车和 Esc 的组字保护，留待实机验证。
