# 键盘逐键成片导出验证（alpha.106，U22c2b5p）

夹具：按键逐键验收.jks（段1 1.315–2.832 秒，keys a@0 / b@500ms / c@1200ms；段2 4.0–4.6 秒，key e@0）。

## 方法

安装包 cap-cli 分别导出键盘 enabled / disabled 的 640×360/30fps 视频；逐帧计算两版差异定位键盘渲染区间；再在底部键盘区域比较连续帧，减去 disabled 版差异得到“键盘专用变化”峰值。

## 结果

- 键盘开/关差异仅出现在 **1.40–2.90s** 与 **4.10–4.67s**，与两个按键段（含淡入淡出）吻合。
- 键盘专用连续帧峰值：
  - **1.83s** ≈ a→b 切换（预期 1.815）；
  - **2.53s** ≈ b→c 切换（预期 2.515）；
  - **2.80–2.93s** = 段1 结束 linger/fade（2.832）；
  - **4.10s** ≈ 段2 淡入、**4.60s** = 段2 结束。
- 键盘 disabled 导出在相同区域无对应峰值（视频内容本身在片头有同现淡入，已用两版差值扣除）。

## 结论

成片导出确实按逐键时间渲染键盘覆盖层（b/c 键切换与段起止/淡入淡出峰值均吻合），关闭键盘后峰值消失。U22c2b5p 的「成片导出逐键」未覆盖项关闭；真实录制生成期过滤、预览窗口逐帧、人工字形/位置观感仍未覆盖。

## 证据

- keyboard-export-summary.json；kb-export.mp4（键盘开）、kb-export-off.mp4（键盘关）；analyze-kb-export.py / analyze-kb-region.py / analyze-kb-only.py 分析脚本。
