# 按键轨道：过滤索引、拖动所有权与快速移动

2026-11-02，U22c2b5源码修复。当前安装仍alpha.54／回滚53；本轮没有操作窗口、打新包或把源码检查当安装版已修复。

## 已复现的实际组件缺陷

使用真实`KeyboardTrack`、Solid store／history、Timeline／Track上下文在JS DOM执行鼠标和键盘事件，13项原始回归全部失败，不是提取后改写的事件逻辑。

原轨道先filter时长外的片段，却用过滤列表的`i()`写原数组。夹具原数组第一项在70秒、第二项在2秒，当前工程60秒；拖动可见项会把隐藏项改成可见项的数据，点击选择／分割也使用错误源索引。测试确认原数据被改写，不能仅解释为显示标签不对。

拖动监听在detached createRoot内，只在mouseup结束；失焦、移除／删除／替换、切编辑模式、缩放时间线／改变时长、鼠标按钮已经松开后仍可能写旧状态。真实history快捷键在手势未结束时触发，历史仍被暂停。原路径也接收非主键拖动／松开。

后续补充回归发现：起点取第一个mousemove而不是mousedown，快速拖动只有一次移动事件时可能完全没有位移；纯点击或被边界夹住的零变化拖动也会多出撤销记录。新增19项中的后一个三场景，在第一版索引／清理修复后仍失败，记录为16通过／3失败，不跳过它们。

## 改动

按片段对象及稳定id找源索引，过滤后的列表只用于显示，选择／分割／写回使用当前源位置；邻居界限按时间排序计算。复用已验证的`createTimelineMouseDrag`，在失焦、Esc、owner移除、模式／比例／时长改变、片段替换或删除、按钮丢失时结束一次，Ctrl／Cmd历史快捷键前也先结束。

保持2像素启动阈值，位移从按下位置计算，保留快速／合并事件的完整距离。只有起止时间真的改变才暂停／恢复历史并写回，避免选择点击和边界零变化产生空撤销。更新只包含start／end，不把按下时复制的其他字段写回；拖动中新的显示文本等值保留。动画曲线、模糊、捕获、编码和画面质量没有改动。

## 检查及边界

19项按键定向检查全部通过，含真实history的Undo／Redo、过滤项保护、选择／分割、九种中断、非主键、两端修剪释放坐标、其他字段保留、单移动事件和空撤销。全界面172项、完整类型、前端构建与作用域Biome通过，见`validation.json`及压缩日志；纯前端修改没有重复原生构建。

从旧起点改为按下位置后，部分断言仍沿用忽略最初3像素的旧数值，另有严格浮点比较导致中间检查失败。按真实指针距离修正期望，秒值以10位精度比较（旧差值0.03秒仍不能通过）；中间日志保留，不把断言错误归为产品缺陷。最终检查全部通过，源码指纹记录在JSON中。

这些测试使用空keys验证轨道几何和生命周期，**未覆盖逐键timeOffset裁剪／重基**；该语义需另核对现有keyboard-timing实现和实际渲染。真实Chromium／WebKit及安装版连续视频验收尚待下一阶段包，不能据JS DOM关闭全部U22或闪屏报告。共享控制器先前其他组件的浏览器／原生证据不能直接算成本组件的新验收。

缩放／3D／Clip／Style／Image、滑块／分隔条与预览写入顺序继续待查。下一继续这些轨道的生命周期和单移动事件，再合入后续阶段包实际检查；初始录制单镜头、U23b2q／U24、完整中文／审计、严格色度两项失败／硬件成片、Windows／Linux和延期实机全部保持。
