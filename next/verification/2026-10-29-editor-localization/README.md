# U07a：编辑器显示调用汉化修复

本轮完成源码修复与前端检查，尚未安装含这些修改的阶段包。当前应用仍为alpha.45，U07/U06父项与逐页运行验收保留，不能将构建成功写成界面已经显示新文案。

## 修改

六类多选数量不再拼接英文单词。字幕显示“已选择2条字幕”的完整句式，按键、文字、音频、遮罩和场景使用相应完整句子；由selection-label.ts根据单/复数选择静态消息键，在调用时按当前语言插值，没有把译文缓存到模块常量。英文保留segment/segments，数字与用户片段名称分开。

裁剪提示的“to skip snapping”接为“可暂时关闭吸附”，原Shift键图形保留。3D轨道两处添加镜头按钮复用已有“Add shot”词条；样式/图片轨的导入和添加图片提示分别接入词典。中文词典增加15个完整消息键，英文使用既有的源消息回退机制。渲染参数、片段/工程内容、按钮动作、图标与动画没有新增变更；ConfigSidebar另有局部格式整理。

对应上一阶段L01至L04，resolutions.json标记为source-fixed-runtime-pending。原始审计报告不覆盖，保留修复前来源。

## 验证及限制

6项新格式检查与3项已有i18n检查通过。格式检查实际调用setInterfaceLanguage与翻译模块，只模拟语言设置的持久化存储和document对象；覆盖六类消息的中文→英文→中文，计数0/1/2/12、英文单复数和变量替换。这是格式层语言切换验证，不是安装版编辑器的DOM/布局验收。

桌面TypeScript检查通过（9.18秒），完整前端构建通过（37.37秒），原始日志压缩保留。生成资源中确实包含新的选择消息键，文件指纹见built-assets.json；它不能证明旧安装包包含修改。局部Biome、全词典插值占位符检查和源码复扫通过，四个目标文件中原来的裸英文片段未再出现；动态键表由格式检查补充验证，不根据静态候选数量宣称全部中文完成。

source-manifest.json保存实际修改文件的SHA；inventory-after.json.gz是本轮源文件复扫快照，sourceCommit指当时HEAD，实际工作内容以文件SHA核对。没有手改生成绑定、增设开发服务器或访问云端。
