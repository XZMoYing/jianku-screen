# 输出比例与透明应用图标验证

目标：演示、视频及截图编辑器提供「适合屏幕」与 13 种固定比例；保留清晰度选项；图标圆角框外透明。

检查包含 52 组比例/清晰度计算、共享渲染器既有比例/裁切/光标回归、桌面 TypeScript、生成绑定、窄范围格式检查与原生编译。打包应用中的工作台检查从实际控件更改设置，通过原生接口核对保存状态，再读取演示通道的帧尺寸元数据，检查固定比例、运行中改清晰度、适合屏幕及窗口调整。

指标不保存屏幕帧、设备标识或录制内容。原稿保留在品牌目录，生产 PNG 与原生 ICNS 检查外角/外边距透明。物理副屏、会议共享、复杂旧工程与长时间运行继续在统一交接清单验收。

最终结果以 `verification.json` 为准。
