# 双模式工作台验证 · 0.2.0-alpha.8

主界面统一为录屏和演示两个模式，演示直接嵌入主窗口。独立滚动区、固定操作栏和窄窗口单列布局均在实际应用验证；模式切换保留留白设置，待机设置写入本地存储；演示启动后只保留主窗口和输出窗口，停止后会话释放。

入口为 [verification.json](verification.json)，原生界面结果在 [workspace-smoke.json](workspace-smoke.json)，输出连接在 [output-client.log](output-client.log)。界面检查使用显式调试开关，在实际 webview 调用控件、输入和滚动；不是模拟 API。正常 860×740 与较小 660×530 均能滚动到内容末尾，操作栏保持可见。

30 项既有几何/权限前端测试、桌面类型与原生检查通过。完整首轮打包见 `initial-build.log`；原生截图检查发现了继承的 Cap 更新弹窗，该弹窗会锁住主窗口。修复后复用未变化的侧车重新打包，最终原生更新接口返回空，实际窗口截图确认遮罩及弹窗消失；正常和窄窗口验证再次通过。编译、打包、开发签名和试用副本严格验证均通过；开发签名不是公证。

本轮未修改动画求解器或着色器。演示捕获画面只在内存中处理；控制界面检查的本地截图留在仓库外。源程序和早期失败/恢复记录保留。实机停止输出时观察到既有 GPU 映射取消日志，未影响停止结果；与其他资源/异常场景一并按 V2-Live-04 继续验收。

未完成的人工观感、明暗主题、快捷键、完整录制/编辑、多屏/会议及 Windows 验收集中在 [交接文档](../../../docs/待验证项目交接.md)。
