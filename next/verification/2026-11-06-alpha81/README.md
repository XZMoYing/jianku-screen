# alpha.81 跨切点缩放验收

冻结源码 011d886，版本 0.2.0-alpha.81／2026.81.0。构建、归档、暂存和本地安装均严格验签，六个可执行文件一致。alpha.80 保留可回滚归档。

- 自有 640×360／24 fps 样本覆盖素材移位、裁剪、两倍速、局部裁切、手动缩放优先、空隙与全屏文字暂停。参照成片 192 帧，编辑后 201 帧。几何对照时屏幕与光标模糊同时设为零，六个选定帧五个与参照逐像素一致，另一帧平均色道差约 0.001713。默认模糊成片与比较数值另存，变速后的模糊量随输出速度变化。
- 导出预览在六个对应时间点的平均色道差均低于 2。安装包内导出程序重新输出 201 帧，与候选侧车成片逐帧一致。
- 实际编辑器通过原生定位与单窗口采集核对六个位置。预览图从左到右、从上到下依次为空隙、移位后局部裁切、手动缩放、自动缩放恢复、全屏文字暂停、暂停后恢复。窗口的定位读数按 60 fps 时间码解释，与导出的 24 fps 取样分别记录。
- 保存重开后，素材、空隙、缩放切片、裁切样式和全屏文字配置一致。应用已打开，停在本轮自有样本。

缩放轨仍以生成组的原时间范围绘制，实际缩放已随素材投影到新位置。下一步让轨道展示实际生效的切片，并提供冲突与缺失提示。跨切点工作流仍待此项，严格色度和设备验收等发布门槛继续。
