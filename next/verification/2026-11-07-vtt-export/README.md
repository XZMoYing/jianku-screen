# 字幕 VTT 导出实际包验收（alpha.91）

安装版 0.2.0-alpha.91／2026.91.0。在自有合成工程（4 条字幕、第 3 条已编辑为 5.157–6.747）上从字幕面板导出 VTT，核对格式与内容；并观察无字幕工程的字幕入口状态。

## 结果

- 操作路径与 SRT 相同：头部「字幕」→ 面板「VTT」→ 原生保存面板（预填 `字幕导出验收.vtt`）→ AX 改名 `字幕导出验收-vtt.vtt` → Save。
- 实际导出内容（237 字节）：

```
WEBVTT

1
00:00:00.000 --> 00:00:01.790
Synthetic Cobalt Lantern

2
00:00:02.090 --> 00:00:04.920
This is an offline diagnostic test.

3
00:00:05.157 --> 00:00:06.747
Synthetic Cobalt Lantern

4
00:00:07.370 --> 00:00:08.000
BLANK_AUDIO
```

- `WEBVTT` 头存在；时间使用点号毫秒 `HH:MM:SS.mmm`；四条 cue 顺序与文本正确；第 3 条为编辑后的 5.157–6.747，说明 VTT 同样读取当前编辑后计时。
- 无字幕工程观察：清除字幕后的同源工程打开时，编辑器头部没有「字幕」入口（素材与片段仍在），因此未出现可点击的 SRT/VTT 导出按钮；这是入口层面的空态行为，导出按钮的禁用提示路径未在本工程触发。

## 未覆盖
