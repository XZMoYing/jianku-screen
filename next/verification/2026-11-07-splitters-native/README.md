# 分隔条（时间线高度／预览编辑栏宽度）原生验收（alpha.91）

安装版 0.2.0-alpha.91／2026.91.0。在自有合成工程编辑器内用真实鼠标事件（CGEvent HID）拖动两个布局分隔条，并用 AX 位置核对布局变化与保存重开后的持久化。

## 定位

- 「调整预览和编辑栏宽度」分隔条：屏幕 (1168,87)，13×554，垂直分隔预览区与右侧编辑栏；窗口相对拖动点为 (1174,339)。
- 「调整时间线高度」分隔条：屏幕 (8,648)，1664×14，水平分隔预览区与时间线；窗口相对拖动点为 (800,630)。
- 轨道头「选择轨道：视频／字幕／按键／缩放」位置用于交叉核对时间线高度变化。

## 结果

| 步骤 | 操作 | AX 结果 |
| --- | --- | --- |
| 时间线加高 | 分隔条 (800,630)→(800,570)，上移 60 px | 分隔条 y 648→588；轨道头整体上移 60（视频 704→644），宽度分隔条高度 554→494 |
| 时间线压低 | (800,570)→(800,670)，下移 100 px | 分隔条 y 588→688；轨道头下移 100（视频 644→744） |
| 编辑栏变窄 | 宽度分隔条 (1174,339)→(1234,339)，右移 60 px | 分隔条 x 1168→1228 |
| 宽度复位 | (1234,339)→(1174,339) | 分隔条 x 回到 1168 |
| 布局保存 | 时间线高度拖到 y608、编辑栏宽度拖到 x1208 后关闭编辑器 | — |
| 重开工程 | 重新打开同一工程 | 分隔条仍在 (1208,608)，轨道头仍在 y664，布局持久化保留 |
| 复位 | 拖回默认 (1168,648) | 恢复原布局，与应用默认一致 |

- 两条分隔条拖动均 1:1 跟随指针、无跳变或丢失；拖动后轨道头与画布区域几何一致更新；无崩溃或配置写入异常。
- AX 中两条分隔条都有本地化描述（「调整预览和编辑栏宽度」「调整时间线高度」），辅助技术可识别。
