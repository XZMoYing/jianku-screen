# 3D 运镜集成：曝光接缝与 alpha.39

日期：2026-10-28。源提交 `92775e929f0f9820dd910b44b2909cf396591270`。本项整合 [透视运动模糊](../2026-10-27-3d-motion/README.md) 与 [自然运镜曲线](../2026-10-28-3d-spring/README.md)。`0.2.0-alpha.39`（`2026.39.0`）已完成整包、实际界面和导出检查并安装打开；整体舒适度仍待用户确认。

## 修复依据

3D 运动原来在每个镜头起点截断过去的曝光历史，即使两个镜头只是同一运动的连续分割。以真实 GPU 导出的九秒合成素材复现：非整帧切分在 30/60fps 分别出现 4/18 个不同解码帧，120fps 的整帧/非整帧切分分别有 101/65 帧变化。视频预测编码会传播差异，这些数量不能当作实际错误渲染帧数。

现在只在能够证明姿态轨迹连续时沿相邻镜头回溯：边界时间吻合、没有内部入出场、全部姿态轴的常量值或弹簧相位、速度、全局幅值与偏置一致。重复分割可以沿链回溯；重叠、不同姿态/速度/相位、真实重复时间不同值的关键帧仍保持切换。静态同姿态也允许保留整卡 2D 缩放的曝光。采样使用当前内容纹理，没有跨镜头读取过去的视频内容。普通缩放、光标、固定焦外与各画面参数保持。

- 修改前后各导出 12 次，最高质量 1280×720，分别为 30、60、120fps。整帧分割和非整帧分割在修复后均与未分割片逐帧相同；未分割片及真正换镜头的片与修复前相同，全部音频 PCM 一致。
- `join-comparison.json` 的 12 项比较全部通过，合计 **7560 对帧**（其中 3780 对检查连续分割）。原始运行、逐帧指纹与日志保留；没有放宽像素阈值或降低视觉质量。
