# 0.2.0-alpha.9 阶段验证

`verification.json` 只保存代码检查、应用内设备录制、工作台和导出的指标，没有手机截图、视频或设备 serial。

实际使用应用的原生设备服务录制 MI 6，等待画面准备后停止，生成 `.jks` 并自动进入编辑器。真实原始视频、缩略图及导出只保存在本机应用数据目录。项目完成状态与可解码媒体检查通过；导出 1080×1920、60 fps、287 帧。这只证明本机该样本的流程，不代替默认声音、普通安卓或 iPad 验收。

自动流程仅由 debug 构建的显式 `JIANKU_MOBILE_SMOKE_OUTPUT` 触发；一次性采集后正常退出验证实例，再无该环境变量地打开试用程序。工作台另以 `JIANKU_WORKSPACE_SMOKE_OUTPUT` 验证手机/电脑入口、工具发现、演示启停、设置保留及较小窗口滚动，未保存用户桌面像素。

启动前后只读检查确认 VPN Hotspot 与 NekoBox 仍在运行，没有执行强停、重启手机、修改热点/VPN/Wi-Fi 或重启 ADB。MI 6 的特殊流程单独匹配，不作为其他安卓机型默认配置。

批准品牌图稿及单色托盘矢量源在 `assets/branding/`，生成后的源拷贝、像素尺寸和哈希已经检查。应用、嵌套原生辅助组件、文件包关联及版本检查通过；本地开发签名不表示已经公证或完成公开发行。

iOS 实机、设备旋转、长录制、真实触摸坐标、完整参考动画和 Windows 保持未验收。详见 `docs/待验证项目交接.md`。
