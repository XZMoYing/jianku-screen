# 缩放轨道原生交互验收（alpha.89）

安装版 0.2.0-alpha.89／2026.89.0。在自有合成工程（`复验（87诊断）.jks`，8 秒单片段）上，用真实鼠标事件（CGEvent HID）操作时间线缩放轨，验证「实时创建、撤销／重做、移动、边缘裁剪、保存重开、Esc 结束语义、片段右键菜单」。

## 定位方式

- 先用 AX 树读出时间线结构：轨道头「选择轨道：缩放」位于屏幕 (25,854)、高 44；缩放轨空白提示「在此轨道拖动添加缩放」位于 (829,869)；编辑器窗口 id 25236／25238，bounds (0,25) 1680×953。
- 缩放轨 lane 取窗口相对坐标 y≈848、x 按时间线像素换算；每步操作前确认应用在前台（工具会激活并校验 frontmost pid）。
- 验证不依赖截图：每步以保存后的 `project-config.json` 的 `timeline.zoomSegments` 为准，并用 AX 节点（「自动缩放」「1.5x」「位置固定在时间线上」「删除全部缩放片段」、3px 边缘手柄、片段右键菜单 7 项）核对界面确实渲染。

## 结果

| 步骤 | 操作 | 结果 |
| --- | --- | --- |
| 创建 | 空白 lane (400,848)→(800,848) 拖动 | 生成 1 段：1.424–3.527 s、amount 1.5、attachment timeline，AX 出现片段与手柄 |
| 撤销 | Cmd+Z + 保存 | 段数 0 |
| 重做 | Cmd+Shift+Z + 保存 | 恢复同一区间 1.424–3.527、amount 与 attachment 不变 |
| 移动 | 段内 (600,848)→(700,848) + 保存 | 1.950–4.053，两端同移 +0.526 s（与 100 px 位移一致，指针偏移在像素容差内） |
| 边缘裁剪 | 右边缘 (898,848)→(950,848) + 保存 | end 4.053→4.326，start 不变；撤销后回到 4.053 |
| 保存重开 | 关闭编辑器窗口、重新打开同一工程 | 配置仍为 1.950–4.053；AX 重新出现「自动缩放」「1.5x」「删除全部缩放片段」等控件 |
| 重开后移动 | 段内 (600,848)→(700,848) + 保存 | 2.476–4.578，再次 +0.526 s，说明重开后的片段按原位置可交互 |
| Esc 结束 | 空白处拖动创建后按 Esc、随即松开鼠标 | 按既有语义保留最后有效范围（5.104–6.104），不产生第二条撤销；随后一次撤销即移除该次创建 |
| 右键菜单 | 片段中央右键 | AX 出现菜单 7 项：编辑此片段属性／定位到片段开头／选中此轨道的全部片段／位置固定在时间线上／关联到 合成语音／固定在当前位置／删除此片段 ⌫ |

- 关键换算：移动与裁剪的配置差值分别与 100 px、约 50 px 的拖动一致（约 190 px/s），未见时间映射用错轴或使用上一次坐标。
- 「Esc 后保留最后有效范围」与 U22c2b7 源码证据里写明的语义一致（已创建时取消保留最后有效范围并结束历史），本轮在原生包复现，不当作缺陷。

## 未覆盖

- 未创建时取消不插入（Esc 在首个有效移动前）、纯点击不增空撤销、相邻片段边界填充、排序菜单（本轮只测片段右键菜单）、完整视频预览与导出、键盘／3D／文字等其余轨道与滑块／分隔条。
- U22 父项与 U22c2b7p 仍不关闭：本证据只覆盖缩放轨四条原生交互与保存重开，不含整片播放／导出成片。
- 未读取或修改用户真实工程；测试工程为 /private/tmp 合成副本，验证后已关闭编辑器。
