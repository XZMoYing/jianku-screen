# 主轨（视频）原生交互验收（alpha.91）

安装版 0.2.0-alpha.91／2026.91.0。在自有合成工程（单段 8 秒画面＋麦克风）上用真实鼠标事件（CGEvent HID）操作主轨：两端裁剪、在播放头处分割、撤销／重做、保存重开与播放。

## 夹具与定位

- 复制自有合成工程为 `视频轨验收.jks`，改写 `recording-meta.pretty_name`。
- 主轨头「选择轨道：视频」在屏幕 y 704，lane 相对窗口中心 y≈701；时间线像素比例约 190 px/s、原点 x≈129；片段从 0–8 秒，左／右手柄 AX 组在 x≈134／1642。
- 空格播放约 2 秒后暂停，可在播放头处按 Final Cut Pro 预设的分割键（Cmd+B）。

## 观察与未决

- **撤销快捷键的焦点前提**：刚完成裁剪后直接从窗口顶部状态按 Cmd+Z 时，配置未变；先点击主轨（时间线获得焦点）再 Cmd+Z 即可撤销。这与编辑器快捷键作用域一致，但本轮未追到具体焦点元素；已作为观察记录，不判缺陷。
- 撤销序列中出现一次「按下无变化」的多余步骤（点击后第一次撤销回退分割，第二次无变化，第三次回退左裁剪），说明历史里可能存在非编辑步骤（选择/预览）。是否应合并或忽略选择步骤，留待后续专项确认。
- 本轮未稳定复现「重做」恢复被撤销的裁剪／分割（两次 Cmd+Shift+Z 均无变化），列入未覆盖；不能据此声称重做通过。
- 主轨整体移动（无空隙工程中受 0 起点与末尾约束）、吸附／磁吸对原生裁剪的影响、转场与空隙组合、拖拽预览观感、成片导出未覆盖。

## 证据文件

- 说明：`vd-step-undo-trim-right`／`undo-trim-left`／`undo-split` 是**未先点击时间线**时的撤销尝试记录（配置未变），不代表撤销失效；点击时间线后的撤销序列见后一组 `undo4／undo-collapsed` 步骤。
