## 根因与修正

上轮安装包中，移动页滚动后切演示再返回，锚点y765→1009，来源/参数仍在。只隐藏/重显MotionPanel的最小页面在Chromium与本机WebKit都保持scrollTop；加入真实MobileRecorder及延迟设备/历史查询后，两者均从300归零。Chromium追踪看见节点在返回页面并刷新查询时isConnected=false，之后重新挂入；本机WebKit同一节点仍在，但重新连接后位置为0。因此不能只加一个定时写回scrollTop掩盖问题。

移动页显示已完成查询的latest值，后台照常刷新设备/历史；首次加载仍走原加载边界，后续刷新不再进入Suspense移走整个滚动节点。保持节点后，两引擎同一路径都从300回到300。查询未完成时禁用开始设备录制，并在实际调用入口再次检查setup.loading，避免缓存设备看起来仍连接却启动采集。正常查询完成、断连判断与新结果仍更新；没有调整平滑/缩放曲线、视觉质量或设备启动命令。
