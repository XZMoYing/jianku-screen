# 编辑器快速标签切换整窗检测（alpha.92，U26 部分）

安装版 0.2.0-alpha.92／2026.92.0。在自有合成工程编辑器中连续快速切换「字幕 ↔ 返回编辑器」与「素材与片段」，用单窗口取帧检测整窗占位/闪变，并核对快速切换后的最终显示是否为最后一次选择。

## 操作与结果

- 点击坐标（窗口内）：字幕/返回编辑器按钮 (1547,51)，素材与片段 (1481,51)；场景共 17 次点击。
- 最终状态：最后一次点击为「字幕」→ 头部按钮变为「返回编辑器」，字幕面板显示 SRT/VTT 与「Synthetic Cobalt Lantern」等字幕文本，**最终显示与最后选择一致，无中间页残留**。
- 取帧：基线 3.5 s／129 帧（最大间隔 40.0 ms，无 >100 ms）；切换 12 s／507 帧（最大间隔 76.7 ms，p95 28.3 ms，无 >100 ms）。
- 全窗统计：luma 212.9–218.2；浅灰占比最高 0.166（基线 0.159）；**未检出整窗加载占位/骨架帧**，未见整窗亮度突变。
- 采集 writer 丢帧 0。

## 局限与未覆盖

- 下采样与阈值使「静止帧」检测把面板切换的小面积变化误判成静止，freezeRuns 不作为主线程卡顿结论；本轮**未测量点击到画面更新的精确延迟**。
- 未覆盖：其他页面/设置页/录制页选项卡、完整入场动画节奏、减少动态效果、快速反向与取消、连续混合操作。
- 取帧最大间隔反映采集调度，不是产品渲染帧率或性能结论。U26 父项保持开放。

## 结论

- 本场景下快速切换能稳定收敛到最后一次选择，且未观察到整窗加载占位；不能据此关闭 U26（性能与视觉节奏仍需专门测量）。
