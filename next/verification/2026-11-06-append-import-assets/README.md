# 追加导入素材准备审计

录制工程追加的两个入口此前直接在目标素材目录分配路径。无效 MP4 在探测前已建目录，复制工程也可能在较晚的片段失败时留下先前复制的素材和光标图。旧目录分配的存在性检查与创建分开，重叠调用可能拿到同一位置。

MP4 通过探测才创建专属暂存目录。工程追加也为每个新片段和这次复制的光标分配专属目录。后台转码任务持有目录直到退出，正常失败时清理本次素材。拒绝链接或重解析点形式的目标素材目录，避免写出工程。元数据开始引用素材时保留它们，即使后续时间线文件写入失败。

macOS 验证运行了实际暂存模块的两项测试，覆盖失败清理、已有及另一批素材保留、目标链接拒绝。桌面 release check 和 Rust 格式通过。尚未安装包含本改动的包。Windows/Linux 运行、应用强制退出后清理、两个工程文件的提交和同工程并发写入仍待处理。
