# 首页三分栏可调原生验收（alpha.92，U25 部分）

安装版 0.2.0-alpha.92／2026.92.0。在首页（工作模式＋捕获来源＋画面设置）用真实鼠标拖动两个分隔条，核对左右宽度、上下高度、最小限制、窄窗退化、重启持久化与录制/演示状态不被重建。

## 结果

| 检查 | 操作 | 结果 |
| --- | --- | --- |
| 左右可调 | 竖向分隔条 x951→1031（+80） | 分隔条 x 到 1031，左侧区域宽度 682→762 |
| 上下可调 | 横向分隔条 y573→513（上移 60） | 分隔条 y 到 513；再下拖到 567 正常 |
| 左侧最小宽度 | 从 x1031 向左猛拖到 600 | 钳制在 x719（左区宽 450 最小），未继续缩小 |
| 右侧最小宽度 | 从 x725 向右猛拖到 1200 | 钳制在 x1047（左区宽 778 最大），右侧保留 |
| 上侧最小高度 | 横向分隔条向上拖到 y200 | 钳制在 y377，未继续压缩预览区 |
| 窄窗退化 | 窗口 1120×800 → 900×700 | 分隔条重新适配（竖向 x811、横向 y413，宽 542／高 582），无溢出或重叠 |
| 重启持久化 | 布局 1047/377 后退出并重开 | 分隔条仍为 1047/377，布局持久化通过 |
| 录制/演示状态 | 切换到「演示」后拖动分隔条 | 拖后仍「录屏=0／演示=1」，状态未被重建；随后切回「录屏」 |
| 复位 | 手动拖回默认 951/573 | 恢复默认布局（应用本身无重置控件） |

- 所有拖动 1:1 跟随指针，无跳动；窄窗与恢复窗口尺寸后布局自适应正常。
- 测量窗口为默认普通窗口 (250,98,1120×800)，非最大化；证据中保留各步 AX 位置。

## 发现的缺口（U25 不关闭）

- **无「重置」入口**：首页与设置中均未找到布局重置控件，源码搜索 `resetLayout`／「重置布局」无结果；用户只能手动拖回。
- **未发现键盘调整**：AXSplitter 没有键盘调整入口，未见箭头/焦点处理；本轮没有实测到可用的键盘调整方式。
- 最小/最大限制只验证了部分方向（左区最小宽 450、右区最小宽约 311、预览区最小高），下侧最大高度与极端分辨率未逐一枚举。

## 未覆盖

- 键盘调整、布局重置、下侧/极端尺寸边界、多显示器与窗口全屏，以及面板内容随尺寸变化的渲染细节；U25 父项保持开放。
