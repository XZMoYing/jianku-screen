# 2026-10-26：长 GOP 定位试验与下一步

当前可试用版本保持 alpha.36。以下是未合入产品的定位原型与诊断证据，不是 alpha.37 交付。所有产品源码已恢复为 `95efbf46a8ed75f4688db4cb844d4528797b7aa9` 的内容，安装应用仍为 alpha.36，未关闭或替换用户编辑器。

## 结论

- 原生准备预览与普通预览的严格整帧断言再次失败。首帧 307200 字节中 1185 字节不同，最大差 8；实际/参考 SHA-256 与上一轮相同。见 [紧凑失败记录](preparing-baseline-summary.log)、[差异指纹](preparing-difference.json)与[合成画面对照](comparison.png)。原始 RGBA 仅含自制噪声图，以 gzip 压缩保留用于后续分层定位。未修改原断言或将此项记为通过。
- 直接把 AVAssetReader 范围起点改为目标秒数会将前一帧重标记为范围起点，像素可能错误，CFR/VFR 均复现。见 [Swift 探针](seek-probe.swift)与[结果](range-seek.json)。按真实样本 PTS、保留其有理数时间基定位可避免该问题，[18 个独立探针点](index-range-seek.json)的 NV12 指纹一致。
- 原型在现有关键帧扫描中附加有界样本时间戳，精确定位只向应用交付目标样本。六种自制素材的 66 个 Rust 检查点，完整 NV12 可见平面 SHA-256 和 PTS 与原关键帧读取路径完全相同，包含 29.97 fps、可变帧率、时间偏移、帧间时间、尾帧、回退与重复定位。见 [四种素材](native-seek-results.json)、[补充素材](native-seek-extra.json)。这不等于 WebView/物理屏幕或完整产品导出的验收。
- **没有足够稳定的代表性性能收益，原型不合入。** 384×216/60fps 的 59.5 秒定位约 691→407 ms；960×540/60fps/fast 编码的同一时刻约 1236→1246 ms，尾端约 1250→1261 ms。样本由 3571/3600 个降至 1 个，解码依赖本身仍然存在；两组机器测量不可当作所有工程的速度结论。未做物理显示或长时间基准，不宣称降低全部预览/导出耗时。
- Homebrew FFmpeg 的首帧软件/硬件解码指纹一致，见 [辅助检查](decoder-backends.json)。它不是应用内捆绑解码器或 GPU 合成路径的证明，不能据此解释准备预览的像素差异。

## 原型与检查范围

[候选补丁](candidate.patch.gz)与[原生取帧检查器](native-seek-check.rs)用于复现实验，未应用到 `next/cap`。在仓库根目录从上述基线解压并应用候选补丁，再将检查器复制到 `crates/video-decode/examples/native-seek-check.rs`，使用生成器在新的临时目录创建素材；在 `next/cap` 中构建 `cargo build --locked --release -p cap-video-decode --example native-seek-check`，再将素材绝对路径依次传给程序。独立执行 release 二进制时需设置 `DYLD_LIBRARY_PATH=target/native-deps/lib:target/native-deps/onnxruntime/lib`；首次未设此路径的测试进程在加载阶段失败，不能当成像素断言的复现。

- [索引检查](index-tests.log)：7 项通过，覆盖时间戳容差/尾帧、缓存容量、文件替换、取消与索引复用。
- [壁纸检查](render-tests.log)：11 项显示通过，其中 4 个依赖 4K 专用变量的测试直接返回，**只计 7 项实际执行**；有效覆盖循环、预读、暂停/模式切换、重开、颜色转换和取消后回零。没有配置 4K 专用素材，不计该部分覆盖。
- [相关编译](check.log)、[检查器构建](native-probe-build.log)、[索引测试构建](index-tests-build.log)、[渲染测试构建](render-tests-build.log)完成。`cargo fmt --all` 已运行；产品源代码恢复后与基线完全相同。原型没有进行正式安装、全段导出或前端类型检查，不具备发布资格。

## 接下来的顺序

1. 对准备阶段整帧差异做分层对照：在应用捆绑库内比较解码后的可见平面，再分别核对屏幕、光标、摄像头和最终合成，保留严格像素门限。
2. 继续长工程、动态壁纸、摄像头、配乐、转场和快速暂停/回退的组合回归。长 GOP 首次定位仍待优化；优先评估可取消预取与重复定位复用，不能使用不正确的旧帧或降低效果。
3. 完善移动/即时/追加录制的书签入口，再做动态文案、本地化与默认视觉校准。物理设备、副屏/会议共享继续顺延，Windows 和正式签名保持后置。
