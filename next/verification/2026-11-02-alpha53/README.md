## 实际文字手势

`拖动与缩放验收.jks`只有本项目自制色条／音调及两个文字片段。工具要求53版本、唯一本产品Editor、自有合成标题、前台及窗口几何匹配；坐标来自实际窗口截图。

- 正常移动：中心x由0.5到0.5818181818181818并保存。
- 移动中Cmd-Z：恢复0.5，继续鼠标移动和松手不写回旧手势。
- 移动中最小化：读回确为最小化，再恢复并等待前台／原几何稳定；后续移动／松手保留中断点x=0.5397106019176136。
- 正常角点缩放：字体48到75.5；撤销后48。再次缩放途中Cmd-Z，后续移动／松手保持48。
- 正常保存、关闭、运行中重开：两段文字配置完全相同。

对应`gesture-*-result*.json`及`gesture-scale-results.json`。这不覆盖替换／删除／空文字的原生场景，相关47项组件检查见上一轮文字手势证据；也不证明其他轨道、滑块、分隔条或连续视频闪屏已解决。

测试过程保留了失败的工具尝试：hide返回false、辅助焦点窗无法激活、最小化恢复尚在动画时几何守卫提前拒绝；最终工具改用最小化读回和有界等待恢复。`native-tool-logs.json`分别记录失败和最终成功，不把工具拒绝当产品回归通过。仅down/up的旧点击未更新hover预览，后改真实mouseMoved/down/up；截图纯色定位也不可靠，最终用实际截图坐标，没有据这两项推断产品故障。
