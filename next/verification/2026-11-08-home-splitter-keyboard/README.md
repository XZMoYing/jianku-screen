# 首页分隔条键盘调整与重置复核（alpha.92）

安装版 0.2.0-alpha.92／2026.92.0。复核第 23 轮「首页分隔条无重置/无键盘调整」的结论：源码 `WorkspaceLayout.tsx` 实际已实现 `role="separator" tabIndex=0`、方向键 ±10、Home 复位、双击复位与持久化；本轮用 AX 聚焦 + 真实按键/双击在安装包内验证。

## 结果

| 操作 | 结果 |
| --- | --- |
| AX 聚焦竖向分隔条 + ← 两次 | 左区宽度 388→408，分隔条 x951→931（每次 10px，方向符合源码） |
| 竖向分隔条 Home | 恢复默认 side=328（x1011） |
| 竖向分隔条 ←×3 后双击（在其新位置 987,538） | 复位到 side=328（x1011），双击复位生效 |
| AX 聚焦横向分隔条 + ↑ 两次 | 上下分隔线 y573→553（controls 高度 +20） |
| 横向分隔条 Home | 恢复默认 controls=254（y613） |
| 键盘调整后退出并重开应用 | 分隔条位置保持（持久化通过） |
| 恢复原用户布局 | 竖向 ←×6 回 side=388（x951）、横向 ↑×4 回 controls=294（y573），与本次开始前一致 |

- 摘要：`WorkspaceLayout.tsx` 使用 `makePersisted` 保存 `workspaceInspectorWidth`／`workspaceControlsHeight`；键盘与双击都会写入这两个值。
- **第 23 轮结论更正**：不是「无重置控件与键盘调整」，而是**能力存在但缺少可发现的按钮入口**；分隔条 AX 未暴露稳定的 `aria-valuenow`，辅助技术不易感知当前尺寸与可用快捷键。记录为可发现性不足，未改产品代码。

## 未覆盖

- 未使用用户真实工程；测试后布局已恢复到本次开始前的默认值（951/573）。
