# 文本轨吸附开关与边缘吸附实测（alpha.94，U29a3b 部分）

安装版 0.2.0-alpha.94／2026.94.0。在自有合成工程中注入两条文本片段（1–2 s「吸附甲」、4–5 s「吸附乙」），验证时间线吸附开关与文本起点边缘吸附到时间线 0 点的行为。

## 结果

| 用例 | 操作 | 结果 |
| --- | --- | --- |
| 吸附开关 | AXPress「时间线吸附」复选框 | 状态 1→0→1（aria-pressed/AXValue 可读）；默认开启 |
| 开启吸附 | 拖文本起点边缘到接近 0 点（目标 x=136，约距 0 点 6px，在 7px 半径内） | **start 精确吸附为 0.0**，end 保持 2.0 |
| 关闭吸附 | 同一拖动路径复测 | start=0.032842（未吸附），end 保持 2.0 |
| 目标过远 | 拖到 x=151（距 0 约 21px，超出半径） | 开/关均不吸附；说明前次无差异是距离超半径，不是开关失效 |

- 结论：文本轨起点边缘吸附按开关生效；`SPLIT_SNAP_PX=7` 的半径按当前缩放换算；复选框可由辅助技术切换并读取状态。
- 测试后工程已撤销回 1–2／4–5，吸附开关恢复开启（默认值），应用正常退出。
