# 在线反馈与本地诊断的文件边界

反馈页已显示敬请期待，但原生 `upload_logs` 和 `upload_diagnostic_report` 仍注册在桌面命令表。原实现可读当天及历史应用日志、诊断 JSONL 和指定报告，再向配置的服务器发送 multipart 请求。发送前的既有字符串脱敏无法可靠识别旧字幕正文。

两个命令保留兼容入口，统一在读取、收集诊断和构造请求之前返回「在线日志反馈敬请期待」。已移除当前 Tauri 应用中的旧上传路径。反馈页、托盘入口和本机诊断显示流程保留。本机新生成的诊断设置快照移除服务器 URL 和实例标识，继续记录录制配置与性能诊断字段。

以当前生产函数体提取的离线测试核对两个调用均同步返回提示，传入不存在的报告也不会读取。检查 Tauri 命令及测试编译通过。未读取、修改或上传历史用户日志或既有报告。完整安装包命令和本地诊断界面待后续包，报告里的其他设备与路径字段、外部引擎输出另行审计。
