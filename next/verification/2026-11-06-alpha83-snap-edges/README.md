# alpha.83 时间线裁剪吸附

在已安装的 macOS alpha.83（2026.83.0）中，用自有八秒素材验证。主视频的第一段止于 4 秒，第二段之前保留间隙，独立样式片段始于 1.25 秒。图片、文字、遮罩、按键和字幕的初始范围均为 2–3.5 秒。

选中片段后拖左右手柄，五类片段左边均吸到样式起点 1.25 秒，右边均吸到主视频终点 4 秒。每次只撤销一次即可恢复，另一边和其他轨道时间保持原值。按 Alt 拖图片左边落在约 1.269 秒，按 Esc 取消字幕右边裁剪后仍为 3.5 秒。保存并重开复核原值，文字预览按画布自动计算的外框位置和尺寸单独排除。测试结束恢复原时间线高度和吸附开关。

首次直接拖未选中的图片左边只到约 1.876 秒。随后从视频选中状态直接拖，以及保存重开后直接拖，均吸到 1.25 秒。首次现象保留待复现，不计入十项边缘结果。字幕右边第一次停在约 3.962 秒，距目标已超过当时的 7 像素吸附范围，重新把手势落在目标附近后通过。实际落点见 `native-results.json`。

首次自有测试夹具包含无效的遮罩类型和按键透明度。已用项目加载器逐项校正并重新打开后再验。校正前观察到编辑器用默认时间线打开，执行保存会覆写原配置。原文件为独立合成夹具，已加入 U09 文件保护审计。3D、场景及其他未测组合和目标平台仍待验证。
