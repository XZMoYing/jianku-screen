# 移动设备外框验证

共用现有矢量栅格化、纹理缓存及 GPU 合成流程；新增手机和平板，不修改镜头、光标或模糊动效参数。外框与画面先合成到同一内容层，再进入已有 3D 运镜。

新设备工程按录制画幅初选外框，宽高较接近的画幅初选平板，长条画幅初选手机；不声称识别实际设备型号。用户可在编辑器切换或关闭外框，并选深浅外观。旧工程不批量更改。

三项录制生命周期检查、五项外框检查及 24 组手机/平板、横竖画幅、输出比例布局组合通过。两份合成工程的 6 秒 / 60 fps / 360 帧导出完成并完整解码；手机实际输出 720×1278（既有自动画布偶数像素计算），平板 1440×1080。附图仅含自建合成素材，没有真实设备画面。

试用工程保存于本机 Movies/Jianku Screen Next/试用 0.2.0-alpha.11；真实 iPad 捕获、声音、动态方向切换及触摸自动跟随仍待验收，不由静态合成素材替代。最终应用与嵌套组件严格签名通过，已打开手机合成工程编辑器。
