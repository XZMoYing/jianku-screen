# alpha.72 工程名输入法验收

冻结 c353519。macOS 构建、严格签名、归档、可回滚安装通过。对照 alpha.70 和 alpha.71 的诊断保存在相邻 alpha.71 目录。最终保留系统原生撤销栈。

实际 macOS 中文输入法输入时，第一次回车提交组字并留在输入框，磁盘名称仍是原值。Cmd+Z 与 Shift+Cmd+Z 恢复原名及已提交文字，转场保持不变。第二次回车离开输入框并保存名称，重新进入输入框可撤销该改动。Esc 先取消组字并保留焦点，第二次退出。离开输入框后，时间线 Cmd+Z 恢复交叉淡化，视频实例身份不变。恢复自有测试标题后保存重开，当前示例保持打开。Windows/Linux 原生输入法需在相应平台验证。
