# 轨道拖动：片段身份与结束清理

2026-11-01，U22c2b1，文字、遮罩、音频轨道源码修复。安装仍为 alpha.50，回滚 alpha.49；本轮未生成新应用包，未据组件检查关闭全部拖动或视频闪屏问题。

## 已确认的问题

新回归直接挂载真实 TextTrack、MaskTrack、AudioTrack、Track 及其时间线 provider，仅替换编辑器上下文、素材和历史/播放头接口。旧代码的22项检查全部失败：18项中断清理未执行、3项未改片段的DOM节点被替换、1项音频跨片段排序后误改其他片段。before.log.gz记录有效复现。最初测试夹具因jsdom缺少ResizeObserver失败，补齐测试环境后才计入这22项产品行为复现；没有把环境错误计成产品缺陷。

音频A从2秒移动到15秒、越过B（10秒）后，旧回调仍持有原数组位置，导致B也被写为15秒。过滤轨道时每次生成新的包装对象，还使Solid的For重建未变片段节点。先前独立监听root的失焦/销毁残留也在三个真实轨道组件中复现，历史暂停无法结束。

## 修正

列表直接以原片段对象为身份，事件使用当前数组位置；拖动与淡入淡出状态也绑定片段对象。位置更新、排序及选中索引重映射在同一批次完成，避免选择跳到相邻片段。

共用拖动监听由轨道owner管理；主要鼠标键松开、窗口失焦、Esc、轨道移除、目标片段删除/换轨、交互模式或显示轨道改变，以及发现漏收松手，都移除旧监听并结束历史暂停一次。开始新拖动先结束前一个。正常松手保留最终坐标；异常中断和Esc保留最后已应用的有效位置，不回滚到旧位置，也不执行点击选择/跳转播放头。音频淡入淡出同样接入，遮罩自身的悬停不再于按键拖动中重复改写预览。
