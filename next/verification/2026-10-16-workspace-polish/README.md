# 主工作台与界面交互验证

版本：0.2.0-alpha.15。环境：Apple M1、16 GB、macOS 14.7.4、Xcode 16.2。

主启动工作台采用简库自己的双模式流程；DogSC 只作交互运动参数和编辑器细节参考。媒体运动、录制和导出算法未改动。

## 自动检查

- 桌面 TypeScript 检查通过。
- 前端 12 项：弹簧保持按压、释放/反向的位置及速度连续性、临界阻尼单调性；既有配色 5 项、窗口几何 3 项。
- Rust 编译检查、窗口相关 61 项既有回归通过；对照实验中的原生窗口类型改动已撤回，没有保留 Rust 源码修改。
- scoped Biome 通过，保留 expressive.css 原有减少动态效果样式的 4 个 `!important` 警告。构建保留上个版本已经出现的 Vinxi/esbuild 类型语法提示；最终 Tauri 应用构建成功。

最终打包检查结果见 [ui-smoke.json](ui-smoke.json)：录前留白保存、演示共用设置、快速设置切换的最终内容与标记、1120×800/660×530 无横向溢出及小窗口滚动通过。设备首次加载保留工作台，移动设备页和演示页具备独立滚动。完整状态见 [verification.json](verification.json)。

## 验证边界

运行环境中的主窗口、设置和编辑器 WebView 都报告 `visibilityState: hidden`，requestAnimationFrame 未持续运行；尝试前台显示、激活及原生窗口类型对照，未获得可靠的可见性证据。没有将这种条件下的测量记成动画通过；`occluded-smoke-attempt.json` 和 `occluded-window-metrics.json` 保存了一次中止记录。临时原生窗口实验已撤回。

最终自动检查会记录动画帧是否可用。不可用时仅检查页面、存储、布局、滚动与业务配置同步，前台按住/释放、连续反向和整体动画观感留待用户实际前台试用。物理动画和隐藏环境中的静态状态不能混为一谈。

`main-wide.png` 与 `main-narrow.png` 使用合成示意内容和内置砂岩背景，不保存用户真实屏幕或壁纸图像。动态主题仍从当前壁纸取得种子色，测试结束后恢复捕获和配色设置。

真实录制、长时间预览、外接屏和设备稳定性继续按 [交接文档](../../../docs/待验证项目交接.md) 验收。安卓静止尾段 P0 未解决；本阶段未录制手机或更改手机进程、网络、ADB、iPad/Windows 范围。
