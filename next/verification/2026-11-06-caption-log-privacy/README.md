# 字幕日志隐私审计

Whisper 应用侧日志曾包含原始音频样本、逐词或词元内容和完整字幕摘要。Parakeet 曾记录识别正文。保存与读取入口也曾打印字幕，并且保存命令的跟踪跨度会捕获完整字幕参数。前端部分错误日志会保留解析错误的原始对象。

本轮移除了这些内容，以及直接记录的媒体、字幕和模型路径。字幕命令的跟踪跨度跳过入参。应用日志保留引擎、阶段、音频汇总、字幕段数和缺少时间戳的数量。文件错误保留错误种类，编解码错误仍保留诊断，界面提示保留。字幕内容、时间映射、工程序列化和 SRT 输出未改。

静态复核应用字幕模块 97 处日志调用和 15 个跟踪入口，未发现被查找的正文、词元、路径或提示词参数。14 项字幕及语言回归、桌面类型、Rust 格式、Biome 和 macOS 原生 release check 通过。未运行带合成音频的完整安装包转写。第三方引擎 stderr、历史文件及反馈上传的脱敏另在 U10b 核查，历史日志未读取或清理。
