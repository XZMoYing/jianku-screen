# alpha.82 缩放切片编辑验收

冻结源码 cfc45a4，版本 0.2.0-alpha.82／2026.82.0。构建、归档、暂存和本地安装均严格验签，六个可执行文件一致。alpha.81 保留可回滚归档。

- 在自有静态网格工程里核对真实缩放切片的显示位置。拖动时按 Escape，工程数据保持。提交拖动后，后段切片在两倍速素材上移动约 0.20 秒，源偏移约 0.4036 秒，前段及整组原范围一致。
- 拖动后段右手柄仅改变相位修剪上界。使用界面剪刀在当前显示的切片上分割，两边原相位和源时刻连续，各自保留偏移及修剪数据。
- 连续三次撤销依次恢复分割、修剪和移动，连续三次重做恢复结果。保存重开后配置与分割状态一致。实际编辑器已打开自有工程并定位到 6.50 秒。
- 包内导出程序生成基线、修剪后与分割后三个 640×360／24 fps 成片，均为 189 帧。前段选定帧保持一致，后段选定帧反映实际位移。修剪后的成片与继续分割后的成片，189 帧解码后全部相同。几何样本将联动模糊同时设为零，正式默认值未参与本轮修改。

定位依据实绘边界。辅助功能给出的可访问宽度包含溢出，首轮探点落到手柄外并创建了额外缩放，已在自有工程撤销。按实绘边界内侧定位后修剪通过。剪刀控件使用窗口坐标，避免跨次读树使用变化后的元素索引。

原始窗口、构建和导出记录在 `/private/tmp/jianku-alpha82-20261106/`。严格色度、硬件成片、延期设备及跨平台门槛继续保留。
