## 结论

- **不是产品缺陷**：文字段左缘像素（x=399）属于时间线车道背景，mousedown 会按「在文字轨空白处拖动新建文字段」的既有设计处理；从 x=400 起（边缘内 1px）即命中起点手柄。之前「重开后起点拖动变新建」的记录来自：拖动起点恰好落在片段左缘像素，加上随后一次多余撤销把先前的移动也回退，导致后续步骤基线错位；本轮已用固定基线与逐步撤销复核。
- 起点手柄在满足时长条件时工作正常：`2026-11-07-text-mask-native` 的干净复验里，先拉长 end 后文字 start 1.0→1.142、遮罩 2.5→2.642，向左扩起点 1.0→0.858／2.5→2.358，两次撤销复原。
- 若要让左缘像素也启动裁剪而不是新建，可另立界面命中区优化项；当前只是 1px 边界行为，不构成「无法拖动」。
- 未改产品源码；探测后夹具已复原为 1.0–2.0，编辑器关闭、应用正常退出。
