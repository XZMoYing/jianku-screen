# U04c：预览分辨率阶段包与验收记录

2026-10-28。当前安装/归档为 **0.2.0-alpha.41 / 2026.41.0**，源码 `0b99a05126727c52ec69dfb357218ea5175c7c8f`。alpha.40 为中间验证包，已被修正版替代。父项 U04/U04c 保持未完成：前台菜单选择、禁用项与播放中直接切换仍待实测。

## 已验证的内容

- 正常 release 入口完整编译、静态前端和严格 ad-hoc 签名通过；构建、安装、归档三处的六个程序指纹一致。见 `delivery-alpha41.json`。未做 Developer ID 签名或公证。
- alpha.40 实际应用收到六组预览尺寸：720p 为 1280×720，144p 为 256×144，2K 为 2560×1440，4K 为 3840×2160，原始画布 4272×2402，小素材原始画布 712×400。alpha.41 复验小素材、4K 和重开后默认 720p 的实际帧尺寸，菜单显示与存储偏好匹配。
- 观察器仅连接当前本产品进程拥有的 127.0.0.1 监听端口，读取 RGBA/NV12 的宽、高、跨度、帧号和数据长度，随后丢弃画面载荷。其他无帧端口的超时保留为观察结果，不混充预览帧；不以单张缓存或时间推进证明持续 GUI 60fps。
- alpha.40 的后台 AX 播放按钮切换及时间推进已观察，实际帧到第 534 帧。两次原生保存界面的 720p60 最高质量导出，预览分别为 720p 与 144p，540 对解码画面及 PCM 完全相同。alpha.41 在 144p 预览下另做一次真实界面导出，与前一份 720p 预览成片再次比较，540 对画面及 PCM 全同。两个比较各 540 对，不把它们当作覆盖所有素材。
- 19 项前端回归、TypeScript 和改动的 Biome 检查通过；原生媒体源码在修正版中没有修改。U04a/b 的真实接口生成、140 画布组合、普通/准备播放回归仍见相邻证据目录。

## 实测发现并修复的缺陷

alpha.40 在小素材中能正确回退尺寸，但受控 Kobalte Select 的回调会把回退值写回全局偏好，`2160p` 变成 `original`，见 `small-preference-observed.json`。修正为忽略与当前有效选择相同的受控回写；正常选择其他质量仍更新偏好。alpha.41 实际打开小素材后，显示原始清晰度/输出 712×400，存储仍为 `2160p`，见 `alpha41-small-retained.json`；大素材实际输出 3840×2160。没有把初次失败删掉或放宽断言。

## 尚未验收的交互

系统实际前台进程持续为 `com.apple.UserNotificationCenter`，普通激活应用无效；检查器在发送全局鼠标输入前停止，没有放松前台保护，也没有操作系统弹窗或更改安全权限。具体通知内容没有读取，不能由进程名推断授权类型。已异步请用户自行查看系统前台状态。

背景 AX 按钮、原生保存界面可操作，但质量下拉使用真实指针/键盘的打开、逐项选择、灰色禁用和播放中直接切换尚未完成。AXPress 与向本产品进程定向投递键盘事件未打开菜单，事件投递成功不是交互通过。不得据此勾 U04c/U04。

质量尺寸复验是在正常退出应用后，仅调整本产品存储的 `general_settings.editorPreviewQuality`，再正常重开独立合成工程。其余存储字段保留；这证明存储→首帧/界面链路，不代替点击菜单的验证。测试后预览恢复 720p，导出恢复 1080p/社交平台/优化文件大小开启。原生保存面板第一次把 AX 写入的完整路径作为带冒号的文件名，生成文件在本项目自有临时目录找到并移动；后续使用纯文件名，未覆盖用户文件。
