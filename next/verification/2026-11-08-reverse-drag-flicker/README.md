# 3D 轨道快速反向拖动整窗检测（alpha.99，U22 闪烁/拖动线索）

安装版 alpha.99。在自有工程 3D 轨道片段上执行真实鼠标**快速反向拖动** 3 轮，单窗口连续取帧，检查是否出现整窗加载骨架/大面积闪变或主线程长间隔。

## 方法

- 每轮路径（相对位置，px）：+40/-80/+80/-60/+60/-40/+40/-20/+20/-10（约 0.5s），轮间 0.9s；共 3 轮。
- 拖动前先 `open -a` 将应用置前，避免事件落到其它 App；单窗口取帧 12s（490 帧，~41fps，writer 丢帧 0）。
- 逐帧全窗 96×54 统计亮度/浅灰占比，与静默段中位数比较；静默段为动作前 0.2s 与最后一轮后 1.2s。

## 结果

- 拖动实际生效：3D 段起点 1.158 → 1.736（约 +110px，与路径 +30px/轮一致）。
- **整窗占位/亮度突变候选帧：0**（suspicious=0）；静默段中位亮度 207.6、浅灰 0.331，动作期间最大相邻帧平均差仅 0.1（片段移动只占窗口小部分像素）。
- 取帧最大间隔 **66.7ms**，>80ms 0 次、>100ms 0 次。
- 局限：整窗统计对局部预览/时间线微闪不敏感，本轮只能说明**未复现整窗骨架或长时间主线程卡顿**，不能据此关闭连续视频闪屏项；需区域聚焦的高帧率分析覆盖局部微闪。

## 证据文件

- `reverse.mov`、`reverse.log`、`reverse-actions.json`：取帧录像、采集报告、三轮事件时间戳。
- `reverse-analysis.json`、`reverse-drag-summary.json`：整窗统计、间隔与结论。
- `ui-drive.swift`（新增 drag-path 路径拖动与稳定激活）、`record-owned-window-cg`、`analyze-reverse.py`：工具源码。
