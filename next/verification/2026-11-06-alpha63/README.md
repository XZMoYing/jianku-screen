## 修复

当前使用的是Cargo.toml patch指定的vendor/tao 0.34.3，其set_maximized在调用时检查旧状态，主队列异步执行NSWindow.zoom。原先builder.maximized和fit后maximize会排入两次切换，可能最终还原。去掉builder的提前请求，尺寸适配完成后仅maximize一次。实际依赖证据见native-queue-evidence.json，不修改依赖或前端效果。
