# 移动画面预览播放平滑度（alpha.108，U26 部分）

夹具：复验工程，把 content/display.mp4 替换为 8s testsrc2 30fps 移动画面（jks 其余不变）。

## 方法

单窗口取帧 6s/162 帧（采集间隔 mean 37ms、p95 68ms、max 82ms），播放约 4.09s；预览区域连续帧差 >0.3 计为一次更新，统计更新频率与停顿。

## 结果

- 播放窗口 capture-rel 1.17–5.26s，活跃采集帧 80，其中更新 72 帧。
- 预览更新 ≈ **17.61 次/s**（受单窗口采集 ~27fps 上限限制；80/4.09≈21.6 采集帧/s）。
- 更新最大间隔 **82ms**（与采集最大间隔 81.7ms 一致），**无 >100ms / >200ms 停顿**。
- 活跃帧差均值 3.54、最大 10.22。

## 结论

移动画面播放 4.09s 内预览持续更新，采集精度内**未发现播放卡顿**；无法验证 60fps 实际刷新/掉帧计数。U26 的播放平滑线索补齐，长时/多轨/导出并行、GPU 指标与真实工程仍待。
