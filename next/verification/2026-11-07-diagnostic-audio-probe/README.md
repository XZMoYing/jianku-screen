# 诊断音频设备探测边界

alpha.86 实际收集阶段未产出报告，栈定位在 CPAL/CoreAudio 的麦克风能力查询。此前在一次同步报告采集中串行枚举音频设备，单个调用卡住会挡住后续的显示、磁盘、测量和报告落盘。

Tauri 将麦克风和音频输出探测放到独立线程，最多等待 4 秒。正常完成时继续使用原设备能力。超时或暂不可用时，报告继续生成，音频设备字段为空，`audioDeviceProbe` 记录状态。系统调用无法由线程超时中断，仍由原线程持有唯一槽位，重试不会不断创建新线程。共享同步诊断入口保留原调用方式。

使用生产探测模块模拟阻塞，验证按期限返回、阻塞期间拒绝重复探测及释放后恢复。macOS 桌面及录制 crate 的 release 测试编译、Rust 格式和差异检查通过。仍运行 alpha.86，尚未打包含修复的应用包，实际报告与 Windows/Linux 待验。
