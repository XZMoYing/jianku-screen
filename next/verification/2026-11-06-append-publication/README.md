# 追加导入的工程文件提交

在自有工程用旧版写入顺序复现。时间线文件设置为只读后，写入返回权限错误，配置字节仍旧，录制元数据却已从一个素材来源变成两个。对应素材会留下，时间线无法反映本次追加。

新入口一次读取两份工程文件，保留原始字节，并在准备素材后核对快照。两份新文件与原元数据回滚文件预先写入并同步，再写入本次提交记录。第二次发布失败时还原原元数据。重新打开或重试时，根据实际两份文件确定清除记录、回滚或保留冲突现场。录制库会尝试恢复可判定状态，便携副本会拒绝未完成提交并排除暂存文件。

当前进程内提交和常规保存通过共用写锁，旧编辑器实例不能覆盖已追加来源的时间线。改名会读回最新元数据再更新名称。仍需验收实际桌面窗口中的操作和提示。其他进程、旧版写入者及断电后的实际平台行为另验，强制退出遗留的未引用素材未做无归属清理。

macOS 上 178 项工程模型测试通过。新增测试覆盖第二次发布错误、字节级回滚、重试、部分和完整提交的恢复、外部文件冲突、旧编辑器保存及过期导入快照。桌面及模型 release check、Rust 格式和差异检查通过。未打包含此改动的安装包。
