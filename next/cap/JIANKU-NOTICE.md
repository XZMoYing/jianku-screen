2026-10-11 的修改包括独立应用标识、隔离日志和设置交接目录、禁用未适配的 GPUI 交接、主窗口尺寸与品牌、本地构建入口和隔离发布配置。录制、编辑、导出和动画核心保留原始实现；当前尚未完成实时演示和动画对照验收。

2026-10-12 增加 macOS 应用包签名与严格验证；默认改为本地录制，主界面及模式说明提供录制与截图，首次引导改为权限与本地功能两步，并使用本项目品牌和权限说明。原生媒体、渲染及编辑核心继续保留上游实现。

2026-10-12 的第二阶段接入本项目既有毫秒积分求解器：光标倾斜改用目标轨迹与条件弹簧，点击缩放改用独立弹簧并保留速度；两者在预览与导出共用有界姿态缓存。倾斜按原始录制尺寸计算；原始位置平滑、镜头、3D 和动态模糊继续使用上游实现。动画逐帧对照尚未完成。

0.2.0-alpha.3 校准缩放模糊的中心选取及画面/光标的平移模糊采样：缩回时优先使用角点运动线交点；21 次平移采样保留，采用重复中心和 0..19/20 的分布。无交点时的回退、中心限幅、缩放采样、透明度处理与原有运动参数保留；完整参考输出对照仍未完成。

0.2.0-alpha.4 校准光标位置的目标时间：移除普通移动的通用预读，用旧目标推进后再更新当前目标/参数；保留点击前瞻和原始模式。位置缓存覆盖最后移动及点击后的实际收尾，超过有界缓存仍以原有解析求解器继续计算；保留上游位置求解器、事件过滤、坐标单位、镜头和画面配置。完整受控输出对照继续待验收。

0.2.0-alpha.5 为 macOS 标准光标增加运行时识别，覆盖辅助功能设置造成的图像变化；缓存遇到新图像时限频刷新。录制资产区分相同图像的不同热点与识别结果，静止时改变外形也写入事件。修正经典 macOS 箭头资产的尖端锚点；macOS 位置采集直接使用 CoreGraphics 小数坐标。光标旋转围绕已记录或内置资产的热点，保持原有倾斜、点击、位置曲线和模糊设置；未旋转时保持既有坐标计算。当前系统设置下的原生识别与 GPU 热点回归已验证，完整实录和参考输出对照仍需验收。

0.2.0-alpha.6 增加本地工程选择、显式保存、可携带副本及最近打开入口。副本嵌入外部录制素材、光标、背景、贴图和音频，改为工程内相对路径；共享渲染器按工程目录解析背景资源。复制先保存最新编辑，再通过临时目录及不覆盖已有目标的原子发布保留完整副本；不修改原始工程、动画曲线和画面参数。原生菜单交互、复杂旧工程及其他平台仍需实机验收。

0.2.0-alpha.7 增加 macOS 实时演示：复用 ScreenCaptureKit 来源及既有 GPU 合成层，接入因果光标/镜头规划、共享窗口、副屏入口和控制页；共享渲染器增加实时样本入口并保留离线路径。演示输出以显示确认约束本地帧通道，编辑器默认传输保持。构建时清理中断签名的临时文件，签名后仍严格验证所有嵌套代码。实时与完整参考动画对照、会议软件及其他平台仍需验收。

0.2.0-alpha.8 重组主窗口为录屏/演示双模式，替换演示控制布局并整理工程和工具入口，补充滚动、设置保存和窗口几何处理。继续复用 Cap 的录制、编辑与既有 GPU 合成核心；本轮不改动画求解器及着色器。上游原生更新流程原先忽略本项目禁用配置，现遵守该配置，不检查或安装上游更新。

0.2.0-alpha.9 使用本项目确认的新品牌图稿及独立绘制的单色托盘矢量图。新建/另存工程采用 `.jks`，保留旧 `.cap` 读取路径，旧 Qt 工程需要另外迁移。移动设备入口使用 macOS AVFoundation/CoreMediaIO 捕获 iOS/iPadOS；安卓通过本机 scrcpy 的独立子进程保存设备原始流，本应用停止仅通知其所拥有的录制进程，不修改其他应用、VPN 或热点设置。设备视频不经过导入转码，进入现有编辑/导出路径；没有原始触摸事件时不合成虚假的点击跟随数据。scrcpy 项目与许可可见 https://github.com/Genymobile/scrcpy ，当前构建使用本机安装版本，未捆绑其二进制。iOS 实机、设备旋转、触摸事件、完整参考动画对照与发行适配仍需验收；Windows 按用户指示推迟到迁入 Windows 环境后处理。
