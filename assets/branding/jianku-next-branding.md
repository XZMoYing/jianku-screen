# 简库镜传 Next 品牌资产

本轮使用用户确认的第二版生图，不重新设计或改变配色。原始 PNG 完整保存在 `jianku-next-logo-approved.png`，保留浅色底、紫色连接画框与克制的蓝、黄绿、薄荷绿内缘。

原图由会话中的内置生图工具生成。用户最后确认的设计要求是：保留新稿的配色和造型，适度保留旧品牌的蓝黄绿圈特色，不张扬但能辨认。本轮只复制批准稿并进行标准尺寸/图标容器导出，没有重新调用生图或重绘其像素。

`jianku-next-tray.svg` 是独立绘制的单色矢量标记，保留两个画框与连接形状，供 macOS 顶栏使用。应用内的 `icons/jianku/tray.svg` 从此源复制；54×54 PNG 是其三倍密度原生模板图标，macOS 以 18 点显示并按菜单栏明暗自动着色。录制时保留明确的停止图标，停止后恢复品牌标记。

可从 `next/cap` 执行 `node scripts/jianku-brand-assets.mjs` 重建应用 ICNS/PNG/ICO 与界面、托盘尺寸。此脚本只读取项目内源资产，不依赖生图服务或会话缓存。保留既有其他尺寸容器，不表示本轮实施 Windows 或移动端应用。
