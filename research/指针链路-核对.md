## 证据等级

- 数值与行为来自官方 3.7.5-4595 的静态研究（[桌面动画处理链](../桌面动画处理链-官方3.7.5静态.md) 第 3 节、[事件与焦点链复核](../官方3.7.5事件与焦点链复核.md)）。
- 本机可用的官方包是 3.4.4-3794；本轮已独立复核其**弹簧数值**与**求解器**（均一致，见 [弹簧求解器核对](弹簧求解器-官方包核对.md)）。指针链路的**原始表达式**在 3.4.4 的字符串表混淆下未逐字复核，故本文件标注为**静态研究依据，待逐帧验证**。
- 严禁在没有对照证据时把下列行为当作"已复刻通过"。

## 已实现的行为

| 环节 | 规则 | 常量 |
|---|---|---|
| 位置目标 | 启用平滑时：未来/当前点击在 500 ms 内 → 用该点击坐标；否则用当前/之前事件坐标；无前序事件回退首个事件 | 前瞻 500 ms |
| 关闭平滑 | 位置目标退化为原始位置；弹簧取 1/1/0 | — |
| 条件弹簧优先级 | ①全局/切片关闭 → 1/1/0；②未来/当前点击 ≤175 ms → 530/40/1；③上一个事件为拖拽 → 1000/40/1；④工程 mouseMovementSpring（默认 470/70/3） | 175 ms |
| 旋转 | `clamp((plannedX(t) − plannedX(t−400)) × 0.03 × cursorRotateOnXMovementRatio, −20, 20) + 基础旋转` | 窗口 400 ms，系数 0.03 |
| 点击缩放 | 下一事件为 mouseDown 且差 ≤130 ms，或下一事件为 mouseUp → 目标 0.8 | 前瞻 130 ms |
| 静止隐藏 | 若 250 ms 内有未来移动 → 可见；否则静止超过阈值 → 隐藏（alpha 0） | 恢复 250 ms |
| 组合弹簧 | 点击/隐藏外层 fader 用 300/30/0.3；内层 mask-blurrer 1430/70/1 | — |
